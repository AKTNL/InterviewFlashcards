# P0-07：正式题库、完整阅读与原文核对

- 状态：已完成（2026-10-31）
- 前置：P0-06
- 接口：[题库与来源阅读](../../api/card-library.md)
- 决策：[ADR 0007](../../decisions/0007-p0-07-card-library.md)

## 交付

新增全题库入口，支持题库/模块/章节范围、题目关键词、未学/已学/到期/薄弱/收藏/待检查筛选、稳定分页、空结果清除条件和重试；显示已确认与待确认章节数。既有逐章确认后的题库链接仍可使用。

卡片详情默认隐藏答案和回忆提示；展开答案直接展示完整跨页内容，追问独立展开。持续显示待检查提醒，显示标签、适用版本、收藏、个人笔记和当前复习状态。原文提取、人工排版/内容修订、个人技术纠错分别标明，未知版本为空。含图片块自动呈现对应整页原图，保留 PDF 来源；提取文本含宽代码/表格时只在内容区滚动。

笔记/提示/要点/收藏独立版本保存，技术纠错/版本/标签使用正式卡片版本，正文/来源/标记复用章节修改协议；全部操作经本地持久队列及服务端收据确认。冲突保留双方并支持下载核对、明确重提。本阶段任何浏览或个人整理均不会生成评分、变更复习日期或清空进度。

新增内置 PDF.js 阅读器，按物理页码定位并高亮来源区域，可翻页、跳页、适屏和放大；所有来源范围都可进入，手机宽度同样可用；本地部署字体/worker/wasm，不依赖外站资源，保留直接打开原 PDF 的兜底。

## 数据与限制

V6 新增 `card.applicable_version/technical_correction` 及查询索引；复用既有标注和标签表。新增 `/api/cards` 查询与写入，无需替换原有内容或重新导入。Nginx 显式设置 `.mjs` worker 的 JavaScript MIME，`/pdfjs/` 的 wasm MIME、无缓存校验和缺失资源 404，避免 SPA 兜底返回 HTML。当前任务未重建 Compose 栈；Nginx/容器验证仍由已有 CI 与 P0-13 发布验收执行。

本阶段不提供评分、学习队列或每日范围设置，分别留 P0-08/09；到期、薄弱和已学筛选已接入现有数据模型，并用真实 PostgreSQL 的已存在状态验证。未来学习页需沿用 `needsCheck` 提醒。全范围同步/恢复闭环仍留 P0-10/11。手机检查使用浏览器 320px 视口，未进行实体手机、其他 PDF 排版或旋转页验收。代码/表格保留原始提取文本与来源原图，不将无法可靠识别的结构推断成排版正确的表格；PDF 全文搜索/文本选择不在本次范围。
