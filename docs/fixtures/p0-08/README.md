## 交付

题库详情可进入单题主动回忆，筛选结果可练习本页。会话保存有序条目、复习版本与当前进度；完整答案、追问、技术纠错、笔记、提示及 PDF 来源可核对，待检查提醒持续展示。只有展开答案才显示“不会、模糊、记住了”；提交禁用重复操作，服务端收据确认后展示日期并前进。断网、丢响应及刷新使用现有 IndexedDB 持久队列和原 operationId 恢复。

纯函数实现 `rules-v1`，正常记住了间隔依次 1/3/7/14/30 天；模糊降一级、不会清到 -1 且遗忘加一次，两者次日到期。所有日期按服务端上海学习日计算。同日所有后续评分均为重练，不升级、不增加遗忘和学习卡片数量，不延后原定日期。自动不会重练每日及每会话最多一次，可跳过；重建会话不能重复领取额度。

评分、事件前后快照、会话条目、重练额度、用户修订号和幂等收据在一个事务内提交。卡片独立复习版本单调递增，即使首次评分撤销后变回未学也不回退到旧版本。撤销保留补偿审计，恢复状态、原位置、重练安排和有效统计；其他设备有后续写入则拒绝直接覆盖。重新学习需确认，日期设今日，保留历史、首次时间和遗忘次数，不再次计新题。事件与状态时间统一到 PostgreSQL 微秒精度，确保首次时间在快照、持久状态及重新学习间一致。

新增 V7：阶段允许 -1～4，卡片复习版本、条目版本及重练/跳过标记、事件种类/顺序/队列快照/提交版本、唯一重练额度表。迁移同步已有状态版本，不修改旧迁移，不清空既有内容或学习日期。

## 复现与边界

常规回归按 [本地开发手册](../../runbooks/local-development.md)：`frontend` 执行 `npm.cmd test`、`npm.cmd run build`；`backend` 使用独立 PostgreSQL 配置执行 `mvn -B -ntp -Pintegration verify`。测试自行建立/清理随机 schema，不使用个人业务空间。

浏览器脚本为 [browser-check.js](browser-check.js)，独立执行器为 [run-browser.cjs](run-browser.cjs)。准备全新的隔离 schema/文件目录，后端账号 `p008-browser`、仅测试密码 `p005-browser-only`（自行生成 BCrypt hash），前端地址为 `127.0.0.1:5174`，同源 `/api` 代理到该隔离后端。本次后端端口 8082、PostgreSQL 18.1 端口 55438。不要使用个人账号；完整脚本只针对尚无评分的新测试空间运行，重复执行需新隔离空间。

从仓库根目录运行 `node docs/fixtures/p0-08/run-browser.cjs`；要求可解析 Playwright 包和已安装 Edge，可通过 `PLAYWRIGHT_MODULE` 指定已安装包的绝对路径、`PLAYWRIGHT_BROWSER_CHANNEL` 指定其他已安装 Chromium 通道。也可经 playwright-cli `run-code --filename=...` 调用业务脚本，但 CLI 确认框接管可能中断长脚本，本次最终使用独立执行器。执行器自动创建证据目录，断言失败以非零退出并保存失败截图。
