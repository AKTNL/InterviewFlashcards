新增 `GroupsIT` 9 项验证：

1. 邀请只对指定账号可见；未接受时没有成员权限；加入默认关闭摘要，逐组授权互不影响。只返回昵称及允许的摘要字段，不含内部用户 ID、卡片、评分或笔记。
2. 撤回后不返回摘要；旧版本授权写入被拒；退出立即失去权限并撤销所有旧邀请，重新加入需新邀请且默认不分享；组主离开解散全组。
3. 过期、撤销邀请拒绝加入，非组主不能发出/撤销邀请，组外账号不能退出或读取小组。
4. 创建、发邀请和接受邀请重试不会产生重复对象，不延长有效期、不重新打开授权；其他账号不能接管同一小组 ID。
5. HTTP 登录、CSRF、显式确认、授权版本校验和退出后读取拒绝；摘要响应 `no-store`。
6. 通过真实学习服务生成评分：同操作重试、同日重练按卡片去重；撤销取消新学计数；上海日期跨 UTC 零点、近 7 天窗口和无有效学习日均正确；与个人摘要相同口径。
7. 实际导出/恢复个人 ZIP：撤回的授权保持关闭，退出的成员不恢复，跨账号恢复不转移资格，其他成员不受影响。
8. 并发接受/撤销只有一个事务先后结果；同一授权版本只允许一个并发写入成功，撤回后旧写入不能开启授权。
9. 服务器执行创建组数量限制；竞争最后一个成员名额只允许一个成功，人数不超过 50。

既有账号、题库复制、文件、同步、导入、检查、学习、数据删除及备份恢复套件继续通过。已更新两处既有重启测试的 V13 迁移数量断言。

前端新增测试覆盖加入/创建明确确认、网络响应丢失保留创建 UUID、摘要单独授权与当前版本、无二次勾选即可撤回、权限刷新失败移除摘要、15 秒及页面可见性更新、解散确认、丢弃旧选择的异步响应，以及刷新时保留邀请输入焦点与内容。

## 浏览器验证

使用独立本机后端/Vite 和临时账号 `p110_owner`、`p110_friend`、`p110_outsider`，没有向真实朋友发送邀请。

- 组主创建“Java 每日互助”，创建前需确认昵称范围，创建后摘要未分享；填写朋友账号发限时邀请。
- 朋友登录看到专属邀请，加入按钮先禁用，勾选说明后加入；加入仍默认关闭摘要，进一步勾选授权才展示日期、时区、今日新学/复习、近一周天数。
- 朋友停止分享后摘要数字消失；确认退出后不再出现在我的小组。组外账号登录没有该组或其成员摘要。
- 桌面 1280×900、手机 390×844 浏览器宽度模拟完成；手机 `documentElement.scrollWidth = innerWidth = 390`，无横向溢出。截图：[桌面](group-desktop.png)、[手机](group-mobile.png)。已目视检查手机截图的提示、授权、成员摘要和退出按钮。
- 验收期间首个未登录 `/api/auth/me` 的 401 符合预期；关闭本机后端后产生的代理连接失败不计为业务验收错误。非零评分的去重、撤销、跨日和统计一致性由 PostgreSQL 测试验证。

## 交付与限制

新增 V13 和“学习小组”导航入口；更新设计/开发文档、API、ADR 和本地手册。部署时与前后端一起升级，先按发布手册保留服务器快照。个人 ZIP 格式和白名单不变，小组关系及授权由服务器当前状态管理。

服务端在撤回/退出提交后立即禁止新查询；其他成员已经看到的页面在下次 15 秒或激活刷新时更新，已传输的信息无法收回。现有所有账号统一使用上海学习时区；没有独立时区配置、排行、聊天、催学消息、组主转让或共同编辑。公网及实体手机验证留待下一次发布，宽度模拟不等同实体设备验收。
