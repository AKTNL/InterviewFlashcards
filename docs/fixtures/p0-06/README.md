## 交付

章节页显示待检查/检查中/已导入及有效题数，提供继续上次检查入口。可编辑问题、完整内容、追问、标记和物理页来源边界；支持合并、拆分、排除，操作需填写原因。合并保留所有来源范围和原始证据；拆分新条目关联原条目。原始识别报告与人工数量变化分开展示，调整记录保存操作前全文、来源和追问。

编辑和检查位置通过 IndexedDB 队列、幂等收据和章节版本保存，收到服务端确认前明确显示待同步。支持响应丢失后刷新、重启应用和独立设备接续。冲突保留本地及服务端全文，允许下载核对副本和明确重提编辑。嵌套 Vue 表单代理在队列边界转换为独立 JSON，兼容 IndexedDB 并固定提交时的内容；PDF 坐标输入保留原始小数精度。

确认前显示有效题数和剩余待检查数，带标记导入必须明确勾选。确认在单事务中生成本章正式卡片及全部来源、追问和拆分父卡关系，其他章保留草稿。重复/并发确认返回稳定映射。已导入章节可修正现有正式卡片，保留 ID、原始证据和学习记录；通过本章正式题库入口阅读全文和核对来源。

暂时退出保留已保存内容；尚未提交的表单离开前提示，已保留至本地队列的操作刷新后可恢复。放弃当前章剩余草稿需要独立确认及原因，保留历史并关闭该章；已导入章节不提供放弃入口。

新增数据库验证：

1. 合并保留全部来源和追问，原始正文证据不丢；数量变化可解释。
2. 拆分新增草稿关联原条目，确认后建立正式父子卡关系。
3. 未明确允许带标记导入时拒绝；同操作及新操作重复确认返回稳定映射，其他章仍待检查。
4. PostgreSQL 触发器在第二张卡片插入时抛错，第一张卡片、来源/追问、章节状态、revision 和收据均回滚；原操作可重试。
5. 正式修正保留 card ID、originalContent 和 review_state/dueDate，更新展示、来源和待检查标记；禁止结构删除。
6. 旧章节版本、越界页码、超出页面范围和旧代次拒绝写入。
7. 整个 Spring 上下文重启后检查位置及状态保留；读、写及正式章节读取均拒绝越权。
8. 放弃需显式确认，只排除本章剩余内容，另一已确认章节卡片保留。
9. 两个线程模拟独立设备并发确认，只创建一组卡片和一个章节修订。

浏览器实际走通：真实 222 页 PDF 的 Java 基础章节编辑；服务端提交后丢弃响应，刷新浏览器后找到原收据且只产生一次编辑；合并 `17→16`、拆分 `16→17`、排除 `17→16` 并核对调整记录；第二个独立浏览器会话恢复检查位置；明确带标记确认 16 题、其余 12 章保留草稿；打开本章正式题库全文。已目视检查桌面及手机截图，未出现页面横向溢出。

## 复现

依照 [本地开发手册](../../runbooks/local-development.md) 设置隔离测试 PostgreSQL，在 frontend 执行 `npm.cmd test`、`npm.cmd run build`；backend 执行 `mvn -B -ntp -Pintegration verify`。

浏览器脚本：[browser-check.js](browser-check.js)。使用隔离空 schema、文件目录及账号 `p006-browser`（测试密码 `p005-browser-only`，沿用上项验收 hash 工具），前端 5173、后端 8080；创建 `output/p0-06/` 后运行：

```powershell
playwright-cli -s=p006 open http://127.0.0.1:5173 --browser=msedge
playwright-cli -s=p006 run-code --filename=docs/fixtures/p0-06/browser-check.js
playwright-cli -s=p006 close
```

脚本会提交一次完整的逐章操作链，已完成确认后重跑需使用新的隔离账号/schema，不覆盖现有卡片。本机最终使用独立 Playwright 进程执行同一脚本；本地结果在 `output/p0-06/browser-result.json`，截图为 `review-desktop.png`、`review-mobile.png`、`cards-mobile.png`。后端最终记录在 `output/p0-06-final-verify.log`。运行数据、临时执行器和截图均不提交版本库。

## 边界

本阶段正式题库只提供当前章节阅读；检索筛选、个人笔记收藏、完整阅读器及学习留 P0-07～P0-09。结构性合并/拆分/排除只用于未确认草稿；已导入内容原位修正，避免破坏学习历史。跨设备全范围同步、恢复备份和完整冲突中心仍按后续任务实施。手机验证使用 320px 浏览器视口，未进行实体手机测试。
