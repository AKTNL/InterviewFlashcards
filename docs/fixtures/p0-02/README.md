截图和本机验证日志位于已忽略的 `output/p0-02/`。Windows 原生 PostgreSQL 为 18.1；本机 JDK 21.0.11 的 Unix socket 临时路径限制通过设置 `jdk.net.unixdomain.tmpdir` 解决，参数见开发手册。应用及 Linux 容器不硬编码此本机路径。

Compose 使用 PostgreSQL 18.3。由于本机容器网络访问默认 Maven Central 域名发生 TLS 重置，官方备用入口下载较慢，本次容器构建通过临时环境变量 `MAVEN_MIRROR_URL=https://maven.aliyun.com/repository/central` 完成。项目默认保留官方备用入口，环境示例和手册说明了镜像覆盖方式；未更改主机配置或引入本机依赖目录。
