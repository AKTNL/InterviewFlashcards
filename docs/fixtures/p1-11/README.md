# P1-11：个人中心邀请码与分步注册验收

日期：2026-11-01。状态：仓库实现与本地验收完成，尚未发布公网；实体手机复验留待发布。范围见 [API](../../api/personal-invitations.md)、[ADR 0017](../../decisions/0017-p1-11-personal-invitations.md) 及 [维护手册](../../runbooks/accounts.md)。

## 自动化验证

- 前端 `npm.cmd test`：136 项通过，含个人邀请组件 5 项、分步注册 5 项；类型检查与生产构建通过。
- 后端 `mvn.cmd -B -ntp -Pintegration verify`：24 项单元测试、103 项 PostgreSQL 集成测试通过，0 跳过，jar 构建成功。
- 独立 PostgreSQL 18.6 Alpine 容器 `flashcards-p111-test`，仅绑定 `127.0.0.1:55441`。测试套件使用随机 schema 并在结束删除；浏览器使用 `p111_browser`。未连接已有部署数据库。

新增 `PersonalInvitesIT` 10 项覆盖：

1. 32 字节随机令牌、仅存摘要、查询仅有脱敏状态、本人所有权；未授权账号不能发码或撤销他人邀请。
2. 匿名预校验不消费、不登录；身份、邀请管理、来源/同步/备份接口仍需认证；预校验与发码校验 CSRF，响应 no-store。
3. 预校验后撤销、过期或邀请人禁用均在最终注册拒绝；到期/撤销不占成功额度。
4. 注册成功增加永久成功计数，单次码不能再次使用；新账号不自动获得邀请权，个人额度耗尽拒绝发码。
5. 用户名冲突及注入 `registration_use` 写入失败触发整笔回滚，无半成品账号、不消费邀请和邀请人成功数。
6. 两个线程同时发码，只有一个成功；只产生一枚有效邀请。
7. 最后一个邀请名额同时注册只有一个成功；撤销与注册并发以锁内先后结果为准，成功数与实际账号一致。
8. 旧维护码继续注册，与个人码竞争最后一个全站名额只有一个成功；达到全站上限后预校验/发码拒绝。
9. 预校验与注册共享来源限流，发码另按账号限流，切换来源无法绕过账号限制。
10. 实际导出 ZIP 并恢复，包内不含明文及邀请权限/记录；恢复不能撤销成功计数、恢复已撤销邀请或改变当前权限。

既有 `RegistrationIT` 另外验证：成功预校验后关闭注册并重启，预校验和最终注册均拒绝；旧账号登录、改密后重启、既有邀请、数据隔离及其他全量套件继续通过。迁移数量断言更新为 V14。

前端测试覆盖发码权限与额度、一次显示及复制、刷新清除明文、响应丢失后先查询且不自动发码、明确撤销后单独生成、离开页面丢弃迟到响应；注册预校验前不显示密码设置，最终失效回到验证步骤保留用户名/昵称并清空密码，网络不确定时只引导先登录、不重放。

## 浏览器与维护演练

本机后端 8087 / Vite 5177，使用临时 `p111_owner`、`p111_desktop_friend`、`p111_mobile_friend`；没有向真实朋友发送邀请。

- 1280×900 桌面：个人中心生成并实际读取剪贴板核对复制；刷新邀请状态后明文消失，只展示脱敏标识。检查 URL、history state、LocalStorage、SessionStorage 和当前站点 IndexedDB 全部 object store，没有邀请码明文。
- 退出后从“使用邀请码加入”验证，确认 `/api/auth/me` 仍为 401；设置用户名、昵称和密码后跳转登录，用户名正确预填。登录进入空资料的“从第一份 PDF 开始”引导；新账号个人中心显示无邀请权限。
- 390×844 手机宽度：拦截发码响应，先让后端真正生成，再中断响应。页面查询到已有有效码，不显示明文，发码请求仅一次；提示明确撤销后另行生成。确认撤销，再生成复制新码，完成验证、设置密码、预填用户名登录及首次导入引导。重新登录邀请人，显示已成功 2/3、剩余 1。
- 手机个人中心及设置账号页 `documentElement.scrollWidth = innerWidth = 390`，无横向溢出；截图已目视检查文字、表单、错误提示及按钮：[桌面个人中心](account-desktop.png)、[手机响应丢失处理](account-mobile.png)、[手机设置账号](register-mobile.png)。截图不含邀请码明文或密码。
- 使用打包的 `AccountAdmin permission` 实际暂停临时账号并将总额调为 1，再恢复授权和总额 3；历史成功数仍为 2，维护审计记录保留。工具不启动 Web 或学习 worker。
- 日志沿用仅方法/状态/耗时的请求记录，不记录 URI、正文、token 或密码，记录对象覆盖 `toString` 脱敏。浏览器的未登录 401 与主动注入的 `ERR_FAILED` 均符合验收预期。

## 交付与限制

新增 V14、个人中心组件、邀请管理与预校验 API、权限维护命令、全站注册上限配置；同步设计/开发文档、API、ADR 和本地/账号维护手册。个人 ZIP 格式及学习同步协议不变。每人总额度须由维护者明确授权；默认不开放注册或邀请扩散。

发布时前后端和 V14 一起升级，先按发布手册保留完整服务器快照。小规模准入采用全站行锁，BCrypt 注册期间其他发码/注册会短暂等待；正常学习不使用此锁。当前浏览器宽度模拟不等同于实体手机或公网部署验收。
