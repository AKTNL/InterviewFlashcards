## 本地浏览器演练

使用 playwright-cli / Chrome，前端 Vite `127.0.0.1:5188`，后端 `127.0.0.1:8080`，独立 schema `p108_browser` 与独立 output 文件目录。视口 360×800 和 1280×1000；无页面横向溢出，注册按钮、字段及返回入口均可操作。

1. 用真实维护工具生成 1 天 / 5 名额邀请，在注册表单分别创建 A、B；成功进入登录页，昵称与登录名分开，使用各自密码登录。
2. 打开第二标签页，退出 A 时另一页清空页面并返回登录；B 登录后旧页保持重新确认身份状态。验证了退出尚未完成时表单等待的修复。
3. 在 B 的账号安全页面修改密码，成功返回登录；用新密码重新登录，旧标签页不恢复原账号同步。
4. A 导入仓库真实 222 页 PDF，解析完成后确认第一章，创建真实卡片的学习会话。通过拦截该标签页业务 POST 模拟短时断网，建立待同步笔记与评分。
5. 在另一标签页直接登录 B。A 原标签页停止并回登录页；B 没有 A 的来源或队列条目，IndexedDB 原 A 的两项操作和 payload 仍保留。
6. 在 B 所在页退出并重新登录 A，原笔记和评分再次出现，模拟断网时继续保留。恢复网络后真实笔记保存为 A 私有内容；评分测试数据补齐会话的 expectedVersion 后提交，收据为 synced，统计 learned=1、todayNew=1、todayReview=0。初次演练构造漏填评分版本被服务端 INVALID_REQUEST 拒绝，没有产生学习事件。
7. 真实交互终端执行维护 `reset`（两次输入、无回显），之前创建的旧会话立即返回 401，旧密码登录 401、新密码登录 200；随后用 `revoke` 撤销演练邀请。密码与会话仅用于隔离测试，不纳入截图或提交。

## 数据归属复核

`SourceService.owned`、Source/AssetRepository 按 userId 读取；页面图片先校验来源归属。导入 job、chapter、draft，卡片阅读与笔记，学习会话与事件，收据/冲突、题库预览/删除/重置均在当前会话 userId 下查询并使用复合归属外键。`BackupService.jobs/job/download/preview/confirm` 校验 owner；替换事务白名单仅学习数据，清理与插入始终限定当前 userId，不写 app_user 凭据或邀请/维护表。

## 发布边界

注册默认 `REGISTRATION_ENABLED=false`，两份 Compose 和环境示例都提供开关及限额。发布前运行完整服务器快照，核对旧账号绑定、真实服务器资源与可信代理；部署后在实体手机和电脑复验。本地视口测试不冒充实体设备或公网签收。回退需要升级前数据库和文件快照，个人学习 ZIP 不含账号和邀请码。
