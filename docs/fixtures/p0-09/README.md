## 交付与验收

首页展示上海学习日、范围内全部到期数、今日新学/目标、今日复习、总已学、章节已学/到期/薄弱和继续入口。提供混合、只复习、只学新题；设置可修改初始建议值、选择已确认章节、设置可空的参考时长。每日计划和偏好写入接入 IndexedDB、版本检查、代次和幂等收据。

| 验收条件 | 结果 |
| --- | --- |
| 新题目标 0、无新题仍可复习，批量不隐藏全部到期 | 数据库验证目标 0、3 张到期截取 2 张、完成后仍显示 1 张并开始下一轮；浏览器空复习轮正常结束 |
| 剩余新题额度只减今日不同有效新学卡片数 | 创建、浏览、重试不减；首次评分后减少，撤销恢复，降低目标到 0 不抹去历史；提高目标重新算余额 |
| 暂停章节跳过任务，恢复显示原逾期日 | 数据库验证旧版本提交拒绝、暂停后有效队列为空、恢复后 dueDate 和历史保持原值；浏览器验证范围暂停与恢复 |
| 关闭重开继续、跨天重算 | 服务端保存原队列和条目；真实 PDF 离开/重新进入/刷新及另一独立上下文均继续同一未处理项；固定时钟穿过上海午夜验证新日额度、旧会话只读和到期优先 |
| 轮末回顾且不宣称全部掌握 | 本轮有效新学/复习数、当前薄弱卡片及遗忘次数；撤销回顾同步恢复；结束提示返回首页查看剩余批次 |

队列读取和评分前都核对范围、卡片状态、复习版本和新题余额，其他会话已处理的卡片跳过，不自动重放旧评分。不符合条件的原始条目保留并返回原因，恢复范围或提高目标后仍可继续符合条件的原条目。手动题库练习继续允许范围外显式练习。

V8 增加会话模式、创建时间、条目类型与恢复索引；未清空数据或修改 V1～V7。读设置不写默认数据。偏好首次版本为 1，更新检查旧版本；当日自动会话版本同步前进。
