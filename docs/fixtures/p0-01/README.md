./tools/pdf-probe/run.ps1 -RenderSamples

前置环境与分步命令见[工具说明](../../../tools/pdf-probe/README.md)。验证结果、完整提取内容和原始坐标会写入 `output/pdf-probe/`；原文不会被修改。

## 数量与链接核对

实际读取 222 页，前 6 页分别解析 25、31、29、29、30、14 个链接，合计 158 个候选，无差异。Java 后端基础 116 道，AI 扩展 42 道，13 章均与设计一致，逐项结果见报告。

全部目录链接为命名目标，PDFBox 解析为 `PDPageXYZDestination`，真实页树决定物理页码。当前页大小 612×792pt，目标 `left=48, topPdf=732`，换算到左上原点约 `(48,60)`；正文标题的保守区域起点通常为 `y=65.25`。目标是带坐标的页内位置，不是印刷页码。当前物理页与印刷页码恰好一致，但工具不读取印刷编号决定目标。

每个主问题当前都从不同物理页开始，未发现同页多主问题，因此不能声称已在当前 PDF 上实测同页多题。构造测试单独验证了同页两标题、同页重复题名按目标坐标消歧、折行标题、重复/缺失目标拒绝。真实文件全部正文片段（去掉页脚）还经过“一次且仅一次归属候选”的覆盖检查。

边界以目录顺序和正文标题匹配确定，采用 `[start, nextStart)`。跨页内页保留；下一题标题之前没有正文的空白区域不算前一题来源页。无法匹配或目标顺序异常时停止生成候选并报告，不能退化为按页切题。

本次共记录 5 个正文片段的字体映射风险、4 个目录条目的同类风险、1 个图片区域和 7 个空白内页。原始目录+正文共有 26 个风险字形；这不等于 26 个最终字符丢失。所有 158 题均带版式保留标记，不能把“来源可追溯”解释为所有答案已完成技术校对。

## 可执行的保留方案

`cards.json` 的每个候选均包含 `sources[].page/bbox`、原始 `textSpans`、`images`、`followups` 和带原因的 `flags`，并携带 `fallback.type=PDF_SOURCE_REGIONS` 与 `requiresReview=true`。不能可靠转换的表格、代码、图示用来源页段保留；当前工具可直接用 PDFBox 渲染任意来源页，完整命令见工具说明。保留整页避免字形框估计导致截断，后续 PDF.js 从物理页和坐标定位。

正式导入链路必须提供原文入口和待检查提示；带标记确认不能静默消除标记。此次不静默补全、不摘要化，也没有覆盖原文件。
