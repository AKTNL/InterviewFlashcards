# P1-04：复习参数配置与效果评估

日期：2026-11-01。状态：已完成仓库实现与本地验收，尚未发布公网。前置 M5 已签收且线上已有学习记录；本次不调整线上数据，测试事件和界面示例不代表真实用户学习效果。

## 交付

- 学习设置新增“复习参数与效果评估”：个人五阶段间隔、范围/顺序校验、必填原因、最近 20 次变更及版本查看；输入和响应不明时保留，重复确认幂等，版本冲突需核对。
- 个人参数追加新版本，后续评分保存版本与完整快照，不批量重算已存在 dueDate。撤销恢复原状态和证据，评分更正沿用原参数；部署默认设置继续兼容。
- 按 30/90/180 天查看安排版本对应的后续到期自评，区分首次、同日重练、提前练习与真正的跨日到期样本；显示三档、样本/题数、准时/逾期、平均间隔与逾期天数。自评不称为客观掌握率或因果改善。
- V18、账号隔离、统一 mutation/修订屏障、同步快照及完整 ZIP 往返；兼容缺少新表/字段的旧格式 1。旧事件缺参数标记未知，删除/重置题库和恢复后重新计算观察结果。

详见 [API](../../api/review-parameters.md) 与 [ADR 0024](../../decisions/0024-p1-04-review-parameters.md)。

前端 **190 项测试**、类型检查与生产构建通过。后端 **24 项单元、141 项 PostgreSQL 集成测试**通过；全量首轮发现一处旧测试仍断言 17 次迁移，更新到 18 后对该套件 12 项全部复验通过。使用独立 PostgreSQL 18.3 临时容器及随机 schema，无现有部署数据库操作。

新增/扩展覆盖个人配置幂等、越界/乱序/空原因、旧版本/旧代次、CSRF/401、账号隔离、收据失败原子回滚、配置不改变既有到期日、新评分版本与快照、UNDO 证据、参数变化后 CORRECT 保留原算法、首次/重练不计样本、不改到期日的重练不抢占旧版本归因、到期结果归因于安排版本、撤销移除样本、重新学习中断链、逾期与跨版本观察、个人参数及效果跨账号 ZIP 往返、旧 ZIP 缺表/字段兼容与非法参数预检拒绝。

前端验证空态、理由与间隔校验、服务端版本回显、响应丢失重试同一操作、冲突编辑保护/显式重读、观察范围、样本分母与旧参数未知标签、错误重试、关闭页面保护。原评分、同步、导入、分享、管理及备份回归均保留。

复验：frontend 运行 `npm test`、`npm run build`；backend 配置隔离 PostgreSQL 的三个 DATABASE_* 环境变量后运行 `mvn -B -ntp -Pintegration verify`。Windows socket/临时目录按[本地手册](../../runbooks/local-development.md)设置。

## 部署与边界

V18 随新前后端一起升级；运行 Flyway，保持原数据库和文件卷。个人参数无需部署重启，默认参数仍可由维护者设置。学习设置进入新页面，需要联网保存；尚未提交的参数不会因离线评分自动应用，响应不明时重试同一操作或重新读取历史核对。正式效果需持续真实复习产生后续样本，不以构造数据宣称有效性。此任务未发布公网或进行实体手机复验。
