## 本次交付

上传来源、唯一导入任务和上传收据在同一事务登记；同文件重复上传复用原来源和任务。单后台工作线程处理持久化队列，显示提取、分析与保存阶段。完整提取证据保存到数据库，重启中断明确标记为 FAILED/INTERRUPTED，重试保留任务 ID 并复用证据。失败状态暂时无法写库时，连接恢复后补写。

Java 后端复用 P0-01 的目录链接、标题位置与半开边界规则，识别模块/章节/问题，合并跨页答案、识别追加追问、过滤孤立页码。显示规范章节名和原名；报告区分目录识别差异与资料基线差异。全部章节、检查进度、草稿、原始内容、来源页段、追问和 READY 状态在同一事务保存。

保留完整文字位置和图片区域；疑似字体映射、特殊字符、空白、图片及代码/表格结构形成带原因标记。页面提供完整原文、追问、逐页 PDF 定位和鉴权页面原图，不以摘要替代原文。原始字体映射中的 NUL 用 Unicode 码点数组无损保存，兼容 PostgreSQL JSONB。

重试接入已有 IndexedDB 队列、操作 ID/代次/版本和事务收据。READY 不允许重解析；失败任务已有草稿也拒绝覆盖。执行令牌/代次阻止旧工作线程落库；人工修改、已确认章节和正式卡片不会被重试删除或覆盖。草稿不生成正式学习卡片。

| 检查 | 结果 |
| --- | --- |
| 前端单元/交互测试 | 35 项通过，包含章节报告、阶段/失败界面、全文和来源、重试收据恢复与版本冲突 |
| 前端类型检查、生产构建 | 通过 |
| 后端单元/契约 | 14 项通过；其中真实 PDF 与边界解析回归 5 项、错误状态补写 1 项 |
| PostgreSQL 集成测试与打包 | 13 项通过，V1～V4 空库迁移、用户/文件/写入协议基线及新增导入风险场景 |
| 真实 PDF 全量回归 | 222 页、158 草稿；模块 116/42、13 章题数及全部逐题正文 SHA-256、起止边界、来源页、追问数、异常类型均匹配冻结基线 |
| 浏览器 | Edge 6 组验收通过，无页面运行时异常；桌面 1280px、手机 320px 和两个独立会话 |

真实解析校验读取原始 PDF，而非生产代码引用期望数量生成候选；测试与生产都使用同一 Java 提取和分析实现。HashMap 保持一个草稿，覆盖第 10～12 页、4 个完整追问。

数据库验证包含：

1. 同文件上传复用唯一任务；真实导入一次保存 158 草稿和 13 章；草稿不参与学习。各新增资源接口验证未登录、越权和页码/分页参数。
2. PostgreSQL 触发器在写入第二张草稿时抛错，验证题库、章节、第一张草稿及关联来源均回滚；原任务为 FAILED。
3. 重试复用已保存证据；暂时移走原文件仍能从证据恢复生成完整草稿。原操作响应重放不再次创建任务/草稿，旧版本冲突。
4. 修改草稿并构造已确认卡片，READY 重解析、旧版本和已有草稿的失败任务重解析均拒绝；旧执行令牌也不覆盖编辑。
5. 解析中关闭整个 Spring 上下文，重启后阶段/进度保留且任务为 INTERRUPTED；显式重试继续。空白 PDF 返回 INSUFFICIENT_TEXT 和重新选择提示；已有正式内容保留。

浏览器验证：真实 PDF 自动后台解析、重复文件去重、13 章报告、HashMap 跨页全文与原图、320px 下仅表格/内容区域局部滚动、刷新后读取持久化草稿，以及第二个独立会话读取相同任务和报告。

## 复现

常规测试依照 [本地开发手册](../../runbooks/local-development.md) 设置真实测试 PostgreSQL，再运行：

```powershell
# frontend/
npm.cmd test
npm.cmd run build
# backend/（需要仓库 docs/ 下的真实 PDF 和冻结基线）
mvn -B -ntp -Pintegration verify
```

浏览器脚本为 [browser-check.js](browser-check.js)。使用隔离测试数据库、来源存储和预置账号 `p005-browser`，对应测试密码 `p005-browser-only`；通过开发手册生成 BCrypt hash。源码前端在 5173、后端在 8080；账号开始为空，脚本支持重复上传同资料复验。创建 `output/p0-05/` 后，在根目录运行：

```powershell
playwright-cli -s=p005 open http://127.0.0.1:5173 --browser=msedge
playwright-cli -s=p005 run-code --filename=docs/fixtures/p0-05/browser-check.js
playwright-cli -s=p005 close
```

本机验收采用独立 PostgreSQL 18.3 测试容器与随机 schema；未读取或修改真实账号数据库。构建记录在忽略目录 `output/p0-05-verify.log`，已目视检查的截图为 `output/p0-05/draft-desktop.png`、`draft-mobile.png`；运行时来源与证据不提交版本库。

## 已知边界

仅支持当前链接目录、未旋转正文的文本 PDF；扫描件/OCR、更多排版与复杂代码表格语义重建不在本任务范围。复杂结构用完整来源与页面原图保留，并持续标记待检查。后台任务按单后端进程运行，不能直接扩展为多实例恢复协调。

本任务只提供完整草稿阅读和来源核对；编辑、合并、拆分、排除、检查位置保存和章节确认属于 P0-06。正式题库和学习仍未开放。
