# P1-13：平台知识库增加、发布与删除验收

日期：2026-11-01。仓库实现及本地验收完成，尚未发布公网。需求见[开发文档](../../开发文档.md#96-p1-13平台知识库增加发布与删除)，接口见 [API](../../api/platform-library.md)，归属与并发决策见 [ADR 0019](../../decisions/0019-p1-13-platform-library.md)。

## 交付与验证范围

- V16：平台命名空间、知识库管理/内容版本、发布快照、每账号一次领取及独立审计；旧账号保持 PERSONAL，不授予任何新角色。
- 管理后台完整复用 PDF 导入、失败状态/重试、数量异常报告、逐章编辑/确认；公共目录展示已发布清单与前 3 题文字预览。
- 发布、下架、不可逆软删除及影响确认；个人副本独立文件，源库修改、下架、删除和源资源清理均不改变副本。
- 删除取消解析令牌；至少 7 天后每小时检查无在途任务、无其他有效引用，再回收源文件。回收失败/中断保留重试标记，保留审计结构及指纹。
- 个人 ZIP 只保留个人副本及来源证据，不恢复平台发布/删除状态或领取次数；全站数据库与文件/临时卷快照覆盖平台内容、快照、领取和审计。

## 自动化

- 前端类型检查、生产构建和 **153 项测试通过**。
- 后端 **24 项单元测试、124 项真实 PostgreSQL 集成测试通过，无跳过**；jar 构建通过。
- 使用本次新建的 `flashcards-p113-test` PostgreSQL 18.3 容器，仅绑定 `127.0.0.1:55443`。自动化使用随机 schema，结束后自动删除；浏览器使用独立 `p113_browser`、独立文件与临时目录。没有连接现有部署数据库或修改线上账号。
- 前端测试覆盖匿名目录预览、完整 PDF 范围、明确领取确认、已领取状态、网络失败原编号重试、管理员发布双重确认/版本与删除影响范围、平台章节检查不进入个人同步队列；原个人章节检查和 P1-09 分享回归保持通过。

`LibraryIT` 8 项覆盖：

1. 平台身份不可登录/启用/提权，排除用户管理列表和详情，不占账号准入；同编号创建幂等，变更请求拒绝。
2. 匿名/普通用户拒绝管理及未发布来源；公开目录不暴露未发布库；管理 CSRF 生效；管理员 PDF Range 与来源原图读取正常。
3. 待确认内容禁止发布，带标记章节需明确确认，过期影响预览及缺失来源权利确认被拒绝；发布原编号重试不增加版本，发布后禁止直接编辑。
4. 领取原编号重试及不同编号重复领取只产生一个题库；新 ID、新文件 key、不导入注释或学习状态。下架阻止其他用户领取，平台修改并重新发布不改旧卡片；删除、7 天资源清理后副本文件仍完整，仍可进入学习及个人 ZIP 导出/恢复，平台保持删除状态。
5. 领取与删除并发只产生完整副本或无副本，两种结果均可按事务核对。
6. 不同操作编号同时领取仍只有一个题库和领取记录。
7. 来源数量配额、文件损坏和收据事务故障不留下可见题库、领取记录或新增文件；P1-09 共享复制逻辑同时回归。
8. 删除在途解析后晚到 checkpoint 被拒绝；不到 7 天不回收源文件，删除成功审计可核对。

复现：按[本地手册](../../runbooks/local-development.md)配置独立 PostgreSQL 的 `DATABASE_*`，运行 `mvn.cmd -B -ntp -Pintegration verify`；前端运行 `npm.cmd test` 与 `npm.cmd run build`。专项可用 `-Dit.test=LibraryIT,SharingIT`。测试只创建并删除自己的随机 schema。

## 浏览器验收

使用独立 Edge 会话及测试管理员/普通账号，桌面 1280px、手机宽度 390px：

1. 管理员新增知识库，上传仓库真实 `Java+agent八股(高频版).pdf`，解析出 **222 页、13 章、158 题**。逐章打开全文及来源，明确勾选保留标记并确认全部章节。
2. 核对发布确认中的 13 章/158 题、0 在途任务和来源提供权，发布后出现在公共目录。
3. 普通账号看到 13 章与整份 PDF 第 1–222 页范围；未确认时领取按钮禁用，确认后领取成功。个人题库显示 13 个已导入章节和 158 张未学卡片；保存个人笔记与收藏并核对服务端确认。
4. 管理员下架后目录为空；重新发布成功，随后删除确认显示 13 章/158 题、0 在途任务、1 人已领取。删除后列表明确显示已删除。
5. 普通账号再次读取已领取卡片，笔记和收藏保留；完整答案仍可展开，PDF.js 实际完成来源第 7 页绘制（`data-rendered-page=7`），总页数仍为 222，并显示来源框。
6. 管理表单、领取确认和删除后来源阅读在 390px 下均无页面横向溢出；账号切换和后端重启期间预期的 401/502 与功能结果分开核对。

## 首期边界

每库一份 PDF，不含 RAG、多人编辑、自动更新或强制撤回个人副本。每账号每库一次领取，删除个人副本或个人恢复不返还次数；历史 deckId 仅用于核对原领取。管理列表保留最近 200 条记录，审计预览最近 30 条；状态审计与领取证据长期保留。平台系统身份不作为人类账号使用。没有部署公网，Dashboard 仍属 P1-14。
