# P0-12 · 响应式、异常体验与数据操作验收

完成日期：2026-10-31。

## 实现

- 首页、导入检查、题库、练习、设置、同步与备份适配手机阅读列；导航可换行，长正文、代码和标识可换行，宽表格独立滚动。三档自评保留文字、键盘焦点和至少 44px 触控面积，图片可打开鉴权原图或来源 PDF。
- 明确展示无题库、搜索无结果、范围无卡片、没有到期题及上传/任务/同步失败，提供导入、清除条件、调整设置或重试入口。评分待处理与正常待同步分别显示，不把失败当作完成或继续自动重试。
- 学习设置新增“题库删除与学习进度重置”：先读取单题库影响计数，再明确确认。删除移除该题库全部内容和历史，保留来源 PDF/图片供显式重新导入；重置仅清除历史及复习状态，回到未学。可先导出完整备份。
- 用户写锁内核对代次/修订，执行清理、会话失效、版本推进与幂等收据；预览过期必须重新确认。跨题库会话整体失效，其他题库历史保留，旧离线评分无法继续写入；响应丢失后从原收据恢复。
- 单题重新学习确认显示题目、原日期、今日日期及历史/首次学习保留的含义。资料改名、设置和卡片编辑提供未保存提示及离开/关闭保护；退出先通过页面保护，未同步时明确提示，退出失败保留错误。初次取得同步快照复用登录代次，避免重新挂载正在操作的页面。

接口：[题库数据操作](../../api/deck-data.md)。决策：[0012](../../decisions/0012-p0-12-responsive-data-operations.md)。

## 真实浏览器验收

使用隔离 `p012-browser` 账号/schema，后端 `8086`、Vite `5178`，Edge 桌面 `1280×900` 及 `360×800` 手机视口/触控上下文。使用原始 **222 页 PDF**。

1. [backup-browser-check.js](backup-browser-check.js)：真实上传、158 张草稿和 13 章；在 360px 视口从章节检查页面明确确认 Java 基础 17 张正式卡片。实际导出并下载 ZIP、核对预览、确认替换恢复；核对笔记/历史/日期/来源和会话往返。独立旧设备离线笔记重连后按新代次隔离，页面异常为 0。
2. [browser-check.js](browser-check.js)：1280px/360px 检查首页、资料、题库、设置、同步、备份和数据操作，均无页面横向溢出；完整答案阅读、来源打开、按钮尺寸及键盘焦点、评分收据确认。另一设备修改后原确认失效；明确重置保留内容/笔记/收藏，旧手机离线评分被拒绝且保留核对副本，旧会话无评分入口。再明确删除题库，验证空态与原 PDF 保留。页面异常为 0。
3. [final-browser-check.js](final-browser-check.js)：实际等待 PDF 第 8 页绘制完成，核对来源高亮和 200% 缩放；模拟 PDF 网络失败后重试成功，真实原图解码为 `935×1210`。验证取消未保存设置退出、取消资料改名导航均保留输入；无效 PDF 明确显示失败且本地文件仍可保存副本，删除后的资料任务提供重试入口。页面异常为 0。
4. [pdf-resize-browser-check.js](pdf-resize-browser-check.js)：清理时从 Vite 日志发现 PDF 画布高度变化引发 ResizeObserver 循环告警；改为只监听宽度、合并到下一帧绘制，增加组件回归。用真实 PDF 验证 `360px → 1280px → 360px` 和 `200% → 适屏`，逐次等待实际绘制完成；通过独立 `window.error` 监听确认循环告警及其他窗口错误均为 0。结果为 `output/p0-12/pdf-resize-result.log`。

按上述顺序以 `playwright-cli -s=p012 run-code --filename=docs/fixtures/p0-12/<脚本名>` 运行。仅可使用隔离账号；脚本会重置、删除该账号题库。最后一项需要预先创建忽略文件 `output/p0-12/invalid.pdf`，内容为任意非 PDF 文本。对编辑确认的接受/取消在浏览器中设置 `window.confirm` 的返回值，退出失败和路由取消另由组件测试验证。

证据位于忽略目录 `output/p0-12/`：导入、完整答案、PDF 绘制、恢复预览与结果、旧设备重置、上传失败及删除空态截图；已目视核对手机 PDF、旧会话失效、备份预览。数据操作结果日志为 `browser-result.log`，最终错误恢复结果为 `final-browser-result.log`，真实下载为 `roundtrip.zip`。

## 限制与后续
