# P1-01：快捷键、阅读设置与返回位置

日期：2026-11-01。已完成仓库实现与本地验收，尚未发布公网。任务依据为[开发文档第 9 节](../../开发文档.md#9-p1核心可用后的增强)，决策见 [ADR 0021](../../decisions/0021-p1-01-reading-experience.md)。本任务仅修改前端，无数据库迁移。

## 交付与使用

- 卡片详情和练习页顶部“阅读设置与快捷键”：16～24px 五档字号，明亮/暖纸/深色三种阅读主题，可关闭桌面快捷键。答案、追问、笔记、提示和技术纠错采用所选字号；来源图片/PDF 保持原貌。
- 空格展开/收起答案，H 展开/收起提示；练习页展开答案后可用 1/2/3 选择不会/模糊/记住了。输入框、编辑区、聚焦控件、选中文字、组合输入、修饰键和长按重复按键均不响应；加载和待同步评分受原有保护。阅读操作不创建学习记录。
- 返回同一卡片或同一练习条目时恢复答案、提示、追问和段落位置；刷新当前页也可接续。查看原文或图片来源后可返回原卡片，练习中的来源页提供“返回当前练习”。新条目和新会话默认隐藏答案。
- 展示偏好按账号保存在当前浏览器；位置按账号、学习代次、内容展示修订及练习条目隔离，仅保留在当前标签页，最多 80 条。提供“从头阅读”。存储不可用或损坏时可继续阅读，不阻塞业务保存。

## 自动化验证

前端全量 **168 项测试通过**，类型检查与生产构建通过。新增阅读面板测试覆盖快捷键评分前置条件、重复键、禁用、编辑/聚焦控件、选区、组合键、偏好持久化、位置与展开状态恢复、账号/代次/条目隔离、重置、损坏和写满存储降级。练习页新增实际 `write` 集成回归：连续不同数字键只入队一次，待同步期间不重复评分。原学习、同步、个人整理、导入与管理页面测试保持通过。

复验：在 `frontend/` 运行 `npm test`、`npm run build`。

## 真实浏览器

使用本地 Vite、独立 Chromium 浏览器上下文、模拟 API 和仓库真实 222 页 PDF。没有连接或修改部署数据库；评分验收核对客户端同步队列和请求，不代替既有服务端调度测试。

- 1280×900：默认答案隐藏，空格/H 展开不产生评分；24px 深色阅读正常。来源 PDF 实际绘制物理页 10，返回时恢复答案、提示、追问，来源段落纵向位置误差小于 1px；刷新后也可接续。
- 编辑笔记时输入空格不切换答案、不评分；关闭快捷键后单键无效。暖纸主题可正常切换。
- 390×844：24px 与深色设置正常，设置项换行、长题目换行，`document.documentElement.scrollWidth === innerWidth === 390`。
- 新练习默认隐藏答案，隐藏时数字键不提交；从来源 PDF 返回同一练习后仍显示原已展开答案，数字 2 通过原同步队列只产生一次 `RATE/VAGUE` 请求，`answerRevealed=true`。无页面脚本错误。

证据：[结构化记录](browser-evidence.json)、[桌面截图](reading-desktop.png)、[手机截图](reading-phone.png)。截图已逐张查看。未操作实体手机，未发布公网。

## 首期边界

阅读位置是当前标签页的便利功能，不跨设备同步，不属于学习进度或个人 ZIP。主题仅影响阅读面板；PDF 原文通过已有物理页与缩放控件阅读。内容修订、恢复学习空间、新会话或新条目会采用新的位置标识。服务端会话仍是练习进度来源，返回时先读取当前状态，不能借阅读位置回退已评分条目。
