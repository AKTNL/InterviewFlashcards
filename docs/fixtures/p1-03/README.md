# P1-03：更多基础学习趋势

日期：2026-11-01。状态：已完成仓库实现和本地验收，尚未发布公网。前置 M5 已签收；任务依据见[开发文档第 9 节](../../开发文档.md#9-p1核心可用后的增强)。

## 交付

- 顶部导航及今日学习增加“学习趋势”，提供最近 4/8/12/52 周记录、新学/复习柱形、学习天数及三档自评次数；标明学习时区、范围和更新时间，空周补零。
- 全部正式章节展示区间前/当前已学、薄弱及差值，区间学习量和当前最近自评题数。暂停章节仍可见，名称和卡片总数取当前内容。
- 遗忘次数大于 0 的题按累计次数、到期日和卡片 ID 稳定排序，分页进入原卡片；包含当前已经记住和暂停章节的题。
- 首页摘要与趋势共用有效事件过滤。评分撤销、更正、幂等重试及同日重练遵守原口径；学习量与自评结果分开显示。只读快照查询，参数校验、账号隔离、刷新/错误/空态完整。
- 无数据库迁移，个人 ZIP 格式不变。新前后端需一起更新；未发布公网、未调整线上数据。

接口见 [API](../../api/learning-trends.md)，统计决策与边界见 [ADR 0023](../../decisions/0023-p1-03-learning-trends.md)。

## 自动化验证

前端全量 **184 项测试**、类型检查及生产构建通过。后端 **24 项单元测试、137 项 PostgreSQL 集成测试**全部通过；使用独立临时 PostgreSQL 18.3 容器和各套件随机 schema，没有连接现有部署数据库。

## 边界

周复习是按日去重后的题次，同卡跨日可多次出现；自评次数包含重练，不作为掌握率。遗忘数取调度状态，与选中周数无关。章节变化基于当前保留卡片及有效历史，删除、重置或恢复后重新解释，不提供历史内容版本快照。本次未发布公网或进行实体设备验收。
