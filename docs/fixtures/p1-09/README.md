新增 `SharingIT` 9 项覆盖：

1. A → B 快照不包含笔记/提示/记忆点/收藏、学习历史/设置、账号凭据、未确认草稿和原解析证据；源内容在创建后修改，领取仍得到原快照。
2. 新卡片/来源/图片 ID 和文件归属独立；标记、纠错、适用版本、追问、标签及支持编辑的草稿关系保持；B 从未学开始、独立评分并通过原编辑接口修改内容，A 的内容、状态与事件保持。
3. B 已上传相同 PDF、重复接受不同授权副本及已有同名标签时仍正常；普通上传去重仍返回原上传。副本完整备份、跨账号恢复后来源证据保持，邀请不进入备份。
4. C 猜测邀请或来源 ID、A 冒充领取、匿名访问、无 CSRF、未明确确认均拒绝。
5. 过期、撤销、已领取、预览过期、代次错误均拒绝；原操作收据可恢复。
6. 注入收据插入失败，题库/资源/领取次数/收据及新发布文件全部回滚；移除故障后同操作可重试。
7. 来源配额不足、快照文件损坏均不生成半成品。
8. 同操作并发领取返回同一结果；领取与撤销竞争只有一个确定结果；双方同时互发邀请无外键锁死锁。
9. A 删除题库及原文件后，未领取快照仍能领取；B 恢复自己的备份会撤销 B 发出的未领取邀请并释放快照，已收到的题库保持。

`BackupIT` 增加 V12 之前格式 1 备份的恢复回归。既有注册、身份切换、文件越权、同步、导入、逐章检查、评分、删除重置及备份套件均通过。前端新增 4 项验证完整 PDF 提示、双端确认、创建/领取网络重试操作 ID 复用，以及过期/撤销/已用/旧修订禁用。

## 浏览器验收

使用临时账号 `p109_owner / p109_friend` 和由 PDFBox 生成的三页空白 PDF（611 字节）及合成卡片，不涉及真实资料或真实朋友账号。桌面浏览器完成：

- A 选择题库和接收账号，预览只有已确认的一张卡片和一章，明确显示完整第 1～3 页；确认权利后创建邀请。
- 退出 A、登录 B，收件箱显示专属邀请。核对数量、完整来源页数和独立学习提示后确认领取；页面显示成功，同邀请再次领取按钮禁用。
- B 的题库显示“未学 / 待检查”，保留 Java21、标签和追问；收藏未勾选，A 的私有笔记没有出现在详情。
- B 的独立来源 ID 可以通过内置 PDF.js 阅读全部 3 页。
- 390×844 视口下分享页面 `scrollWidth = innerWidth = 390`，长哈希换行，确认按钮适屏；来源阅读适屏。
