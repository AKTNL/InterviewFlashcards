# P1-12：管理员账号、用户管理与权限配置验收

日期：2026-11-01。状态：仓库实现与本地验收完成，尚未发布公网；没有调整线上角色、注册开关或配额。需求见[开发文档](../../开发文档.md#95-p1-12管理员账号用户管理与权限配置)，契约见 [管理 API](../../api/admin-accounts.md)、[ADR 0018](../../decisions/0018-p1-12-admin-accounts.md)、[维护手册](../../runbooks/accounts.md)。

## 交付

- V15：USER / ADMIN、启停、首次改密、管理版本、最近登录；永久管理建号名额和幂等收据；扩展管理审计。
- 管理后台：用户列表搜索/筛选/分页、详情和实际文件用量、新建普通用户、启停、密码重置、邀请授权/累计总额度/撤销、审计和只读全站限制。知识库与 Dashboard 明确标注 P1-13 / P1-14 待实现。
- 首个管理员交互创建或精确绑定旧账号；角色回收只走受控命令，保护最后一个启用管理员。旧预置绑定和凭据不变，迁移不默认提升任何用户。
- 逐请求读取当前状态与角色；初始/重置密码先改密，旧会话撤销、权限回收及邀请码失效即时受控。管理员普通学习接口仍限定本人归属。
- 管理建号和邀请注册共用全站锁与上限；重复提交、响应丢失、事务失败不重复建号或超发。管理操作不进入普通离线队列，个人恢复不改变管理与准入数据。

新增 `AdminIT` 13 项覆盖：

1. 旧预置身份默认 USER、原密码和学习空间保留；ADMIN profile 仅提供声明的稳定能力。
2. 真实 V14 → V15 升级：保留旧账号 UUID、精确旧登录名、密码 hash、预置绑定及已有成功邀请数，不自动授予 ADMIN。
3. 匿名/普通用户拒绝管理 API；管理 CSRF 生效；现有会话的管理角色回收下次请求被拒绝。
4. 建号响应丢失后同编号返回同 ID，变更内容复用编号拒绝；默认无管理/邀请资格；初始登录仅允许改密，不能使用原密码充当新密码，改密后旧会话失效。
5. 停用/启用及密码重置撤销旧会话；启用不恢复旧邀请；账号 UUID、epoch、资料保留。
6. 邀请成功数永久保留，回收权限撤销未消费码，调低或重新开放不清零成功数。
7. 目标管理员、跨用户邀请 ID、过期管理版本、JSON 注入 role 均拒绝；管理员也不能读取他人来源详情。
8. 用户搜索、启停/资格过滤、分页上限与只读全站配置；详情没有密码、hash、令牌摘要或私人学习内容。
9. 管理建号与邀请码注册竞争最后一个全站名额只有一个成功；两个并发同编号建号只有一份账号。
10. 分配记录写入失败整笔回滚账号、名称预留和名额；成功/失败审计不含密码。
11. 个人 ZIP 不包含角色、密码、邀请、管理收据或审计；测试服务层恢复后停用、角色、邀请配置和审计保持。
12. 真实维护进程绑定旧账号保留密码和 epoch，两个管理员并发降级只允许一个成功，最后一个启用 ADMIN 保留。
13. 用户自行改密推进管理版本，旧的管理员重置预览不能覆盖用户刚设的新密码。

既有 103 项集成用例继续验证注册关闭、限流、邀请码、私有空间、共享副本、小组、同步、评分及 ZIP 往返。迁移数量断言更新为 V15。前端新增管理页面 7 项，以及首次改密直接跳转和 profile 刷新不产生导航循环的 2 项回归；覆盖明确确认、版本、响应丢失不自动重试、建号编号复用、权限失效清空数据、刷新保留输入和丢弃迟到详情。

## 限制与发布

仅完成本地验收，实体手机和公网升级须随 V15 发布后复验。初始化管理员必须由维护者指定身份并交互设置凭据，不内置默认管理员/密码。后台全站环境配置只读；个人 ZIP 不是整站账号迁移/回退工具。升级和回退沿用完整服务器快照，保留数据库、文件、暂存和配置。

小规模管理采用全站行锁串行化准入与写入，BCrypt 期间其他注册/管理请求短暂等待；正常学习不使用此锁。文件用量按页计算，最大 50 人/页。在线时长尚未采集，知识库发布和 Dashboard 留 P1-13 / P1-14，不能把入口视为已实现业务。
