## 边界

P0-04 写入协议/同步队列、P0-05 解析任务与草稿、后续题库/学习/备份业务尚未实现。基础迁移包含这些实体的表和约束，业务映射与行为留给对应任务，不以空接口模拟成功。当前资料页明确区分“原文件已保存”和后续解析/检查。

会话为进程内会话，后端重启后需重新登录；账号和原文件持久化。公网必须启用 HTTPS 和 `SESSION_COOKIE_SECURE=true`，生产证书/域名和发布仍属于 P0-13。浏览器验收为 Edge 桌面及手机视口仿真，未使用实体手机；GitHub CI 配置已更新，本次为本地验证，未触发远端执行。
