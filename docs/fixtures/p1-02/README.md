# P1-02：导入检查效率优化

日期：2026-11-01。已完成仓库实现与本地验收，尚未发布公网。任务依据为[开发文档第 9 节](../../开发文档.md#9-p1核心可用后的增强)，决策见 [ADR 0022](../../decisions/0022-p1-02-import-review-efficiency.md)。仅修改前端，无数据库迁移。

## 交付与使用

- “我的资料 → 查看章节与草稿”可只显示有待检查题的章节；逐章检查支持异常类型、待检查/已排除范围及题目关键词筛选，直接查看异常原因与物理页。上一/下一待检查题按当前筛选循环，继续保存服务端检查位置。确认章节始终覆盖全章有效题，筛选后仍显示完整确认数量。
- 当前题目显示本章相似标题数量、相似度和前五项，可只读展开候选的完整答案、追问、原始证据及来源。自身和已排除项不参与；提示不自动合并、排除、选中或写入进度。确需合并时仍要手动选题并填写原因。
- “原文并排对照”支持编辑与 PDF 同屏，来源段落选择保留跨页和同页多范围，提供物理页跳转、高亮、缩放、失败重试及原 PDF 兜底。桌面双列，手机顺序排列；PDF 按需加载。管理员平台知识库复用同一组件，使用独立鉴权来源路径。
- 草稿、来源、章节版本及调整记录的输入/输出 ID 可直接核对；原始提取证据仍可展开。未保存编辑及待同步写入继续受保护，异常只能经明确编辑与原因保存解除。修复连续异常复选框在移除首项后错误显示下一项未勾选的问题。

前端全量 **180 项测试通过**，类型检查与生产构建通过。新增回归覆盖标题归一化、相似度边界、重复字符、排除/自我过滤、只读对比不写入、不自动勾选、旧对比响应隔离、异常章节筛选、类型/关键词与异常导航、筛选不缩小确认范围、清理隐藏合并选择、编辑保护、按原版本保存、剩余标记保持勾选（包括同页同原因的多个标记）、多来源段落及无效 bbox 降级、来源移除后的选择回退、平台 PDF 路径切换。

## 真实浏览器

独立 Chromium 上使用本地 Vite、隔离模拟 API 与仓库真实 222 页 PDF；未连接部署数据库。模拟 API 用于核对前端提交及队列，不替代服务端集成验收。

- 1440×1000：检查编辑区与 PDF 各 532px 并排；物理页 10/11 切换成功，同页两个来源框可单独选择。逐项移除表格标记后字形标记仍保持勾选，编辑期间筛选/异常导航禁用。
- 390×844：检查内容和 PDF 均为 350px 单列；页面 `scrollWidth === innerWidth === 390`，工具栏换行，PDF 高亮正常。桌面及手机截图已查看。
- 相似题只读对比没有写请求或合并勾选；已排除题不出现在相似/异常结果。按原章节版本 4 提交一次 `EDIT`，仅保留 `GLYPH` 标记并将修改内容明确为 `MANUAL_TEXT`；原始证据保持。历史显示输入/输出 ID。
- 下一待检查题经原同步队列提交 `PROGRESS`，使用章节版本 5；刷新并重开章节后恢复已保存的当前题。未发生评分、自动合并或自动清空标记。
- 管理平台原文使用 `/api/admin/library/{id}/sources/{source}/content` 实际绘制物理页 12；模拟 PDF 请求失败时显示重试及同一命名空间的原 PDF 链接，恢复网络后重试成功。无页面脚本错误。

## 首期边界

相似题是本章标题文字提示，不比较答案语义或跨章/跨资料去重。筛选、对照开关与当前来源段落仅服务当前页面，不跨设备同步；已保存的检查位置仍由服务端同步。异常集中处理不代表自动核对全部内容。尚未发布公网，未操作实体手机。
