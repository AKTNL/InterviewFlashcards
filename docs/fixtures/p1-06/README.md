# P1-06：多个独立题库的管理体验

状态：已完成仓库实现与本地验收（2026-11-01），尚未发布公网。

## 交付

- 新增“题库管理”：按名称、完整 ID、来源文件查找，同名题库显示完整 ID，各自展示章节确认、选中范围和已学/未学/到期/薄弱；空题库可见。
- 卡片按题库立即切换，清除旧模块、章节和分页；结果展示所属题库。浏览不改变每日学习范围，管理页到期包含暂停章节。
- 按来源 SHA-256 提示相同文件的独立副本；按标题忽略空白和大小写提示正式题重复，支持按题库、章节、关键词和状态分页核对。提示不自动合并或删除，现有重复上传行为保留。
- 学习设置支持按稳定题库 ID 筛选和批量选择/暂停显示章节，保留其他题库选择；整体保存沿用同步版本与队列。全局每日目标不拆成每库配额。
- 删除/重置入口预选目标题库，预览展示完整 ID，继续要求读取影响、显式确认及服务端收据。

## 真实浏览器

使用 playwright-cli 技能、独立 Edge 会话、Vite 与最新后端 JAR；1440px 桌面及 390px 手机宽度。专用合成数据包含两个同名题库（A 已学 1/1，B 未学 1/1）、相同来源指纹及一个空题库；来源为合成元数据，本次不重复验收 PDF 渲染。

| 操作 | 结果 |
| --- | --- |
| 查找“朋友副本” | 只显示 B，各自进度和相同文件提示可辨识 |
| B 的重复题入口，再切换 A | 都只返回各自题目，URL 使用独立 deckId |
| B 的学习范围，全选显示章节后保存 | 收到同步确认，切回全部范围仍有 A/B 两章选中 |
| B 的删除入口 | 只预选 B；手动读预览，完整 ID 可核对，未确认不可执行 |
| 明确确认删除 B，再返回管理 | B 消失，A 仍已学 1/1，孤立来源不再产生重复库提示 |
| 手机管理及设置 | 无页面横向溢出，操作可见，无 pageerror |

截图展示两个同名题库与空库、范围保存后的实际页面：[桌面](desktop.png) · [手机](phone.png)。删除演练后在隔离数据中重建合成副本，记录最终样式。控制台仅出现首次未登录身份检查的预期 401 和写入前查询尚不存在收据的预期 404，未出现页面脚本错误。

## 发布与限制

更新前后端，无新增迁移，沿用 V19。现有数据库、文件卷、稳定卡片 ID、历史与 ZIP 格式保持兼容。上线后从“题库管理”进入，来源页也提供入口；恢复、删除及远端评分沿用现有同步刷新。

本任务不提供语义查重、跨库自动合并、单卡删除和每库每日配额；相同标题可能存在不同答案。大规模题库摘要分页与标题索引尚未引入。完整字段和边界见 [API](../../api/deck-management.md)，决策见 [ADR 0026](../../decisions/0026-p1-06-independent-deck-management.md)。
