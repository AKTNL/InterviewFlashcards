# P1-06 多题库管理

沿用登录会话与标准响应包装；所有查询只读取当前账号，不接受其他 userId。无数据库迁移，查询不写入修订、学习历史或学习范围。

## GET /api/cards/decks

在同一个 REPEATABLE READ 事务中返回题库与来源总览，包括暂无模块/章节的空题库：

```json
{
  "decks": [{
    "id": "uuid", "name": "Java 面试", "total": 25, "learned": 3,
    "due": 2, "weak": 1, "duplicates": 1,
    "chapters": 2, "imported": 1, "selected": 1
  }],
  "sources": [{
    "deckId": "uuid", "id": "source-uuid", "name": "Java.pdf",
    "sha256": "64位摘要", "sharedCopy": false,
    "jobId": "job-uuid", "status": "READY", "sameFileDecks": 1
  }],
  "learningDate": "2026-11-01"
}
```

- `total` 仅统计正式卡片；`learned` 为有当前复习状态的卡片，`due` 为上海学习日到期/逾期，`weak` 为最近有效评分不会/模糊。到期和薄弱包含暂停章节，与首页仅统计学习范围的到期数有所区别。
- `chapters` 为全部章节，`imported` 为已确认章数，`selected` 为当前每日学习范围选中的章数。每日新题目标仍由全部已选章节共用。
- `duplicates` 为本题库中存在其他同标题正式卡片的题数，匹配可来自本题库或本账号其他题库。按数据库 POSIX 空白移除后转小写比较；空白标题不匹配。它不代表答案相同，也不代表重复的复习状态。
- 来源取当前仍关联题库的导入任务；`sameFileDecks` 按 SHA-256 计算关联相同文件的其他不同题库数。已删除题库保留下来的孤立来源不计入。
- 同名题库按名称、完整 ID 排序；前端显示完整 ID 并支持按名称、ID、来源名称查找。不会向其他用户暴露题库、来源或重复数量。

## 卡片与学习范围

`GET /api/cards` 增加 `filter=DUPLICATE`，可与现有 deckId/moduleId/chapterId、字面关键词和分页组合。先在当前账号全部正式卡片中判断重复，再筛选返回范围。因此切换到一个题库后仍可看见它与其他题库的重复提示。计数、排序与分页沿用原契约。每个列表项增加 `deckId`、`deckName`，同名题目也能区分来源题库。

`GET /api/today` 每个章节增加 `deckId`。学习设置按稳定 ID 筛选和批量选择/暂停当前显示章节；隐藏题库的已选章节仍随完整 `chapterIds` 提交。使用原 `preferences.save` 版本、代次、离线队列与冲突处理，不因浏览筛选自动保存。

`/data?deckId=uuid` 只预选操作题库；原影响预览、用户修订、显式确认、同步收据和旧会话失效规则继续适用。预览展示完整题库 ID，不凭同名名称决定删除目标。相关混合会话整体失效，其他题库内容与历史保留。

## 去重边界

直接重复上传 PDF 继续返回原来源及导入任务；授权领取的副本继续允许相同 SHA-256。重复题提示不自动合并、排除、删除或共享学习记录。逐题查看来源并保留不同答案；需要清理整份副本时从题库管理进入原删除流程，先备份、核对范围并确认。单卡删除/跨库合并不在本任务范围。

总览适用于当前个人与朋友规模，返回全部题库摘要和来源；未增加大型题库的服务端摘要分页、模糊语义查重或标题索引。
