# ADR 0005：持久化 PDF 导入与来源保留

- 日期：2026-10-31
- 状态：采用
- 范围：P0-05，单后端进程、当前链接目录 PDF

将 P0-01 的 PDFBox 文字/字体/图片区域提取与目录定位规则移入 Java 后端。生产环境不调用 Python，不读取测试基线生成数据。前六页目录链接和正文标题坐标决定问题半开边界，跨页内容合并，过滤孤立物理页码；章节别名只规范显示名称并保留原名。

数据库保存任务、提取证据、报告与最终草稿。单工作线程轮询持久化队列；PDF 提取与分析在事务外运行，短事务保存阶段和进度。完成时持用户锁，在同一个事务内保存题库/模块/章节、检查进度、全部草稿、来源范围、追问及 READY 状态和用户 revision。半途失败不留下半套题库。

上传来源和任务登记沿用统一业务收据事务。重试也使用代次、版本、摘要和收据；执行令牌阻止旧尝试落库。重启将 PARSING 任务明确标为 FAILED/INTERRUPTED 并保留阶段和证据，用户重试继续；QUEUED 自动执行。数据库暂时断开导致错误状态未保存时，工作线程在重新连接后补写，不让任务一直停在 PARSING。

不提供 READY 任务重解析。即使失败任务已有草稿也拒绝重解析，避免覆盖编辑或删除已确认内容；P0-06 后的编辑和确认走独立业务接口。该限制比静默重建更容易保证稳定 ID 与学习记录。

内容保留完整文字、位置、字体异常证据、追问和来源图片区域。原始内容与展示内容分列保存。图片和复杂代码/表格首版通过受鉴权的完整 PDF 与按需页面 PNG 保留，不猜测结构、不生成摘要。整页图片明确标明可能包含相邻内容，并显示本题页内边界；不提前生成重复的整页资源。字体映射中的 U+0000 用 Unicode 码点数组无损保存，兼容 PostgreSQL JSONB。

报告分别显示“目录 → 草稿”的识别差异和“当前资料基线 → 实际”的数量差异。222 页/158 题、模块与章节预期只作校验；无法定位或乱序的边界明确失败，不能伪造数量通过。

代价与限制：提取证据增加数据库占用；页面 PNG 首次查看需要服务端渲染；当前轮询器按单后端进程运行，不支持多实例同时启动时的恢复协调。更多排版、OCR、复杂语义重建及分布式队列均超出本任务。
