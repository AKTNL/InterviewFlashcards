# ADR 0022：导入检查的相似题提示、异常集中与原文对照

日期：2026-11-01。状态：采用，仓库实现，尚未发布公网。

P1-02 在现有 `ChapterReview` 上增强检查效率，个人导入和管理员平台知识库共用。保持既有章节版本、草稿版本、稳定 ID、来源范围及审计协议；不增加数据库迁移、解析规则或写入接口。

相似题仅比较当前章未排除草稿的标题。标题经 NFKC、小写、开头题号及标点/空白归一化，用相邻双字符的多重集 Dice 重合率计算。至少两个字符的完全相同标题可提示，非完全相同标题至少四字符且相似度不低于 0.65；按相似度和稳定 ID 排序，展示总数及前五项。计算留在前端，不引入 AI、全文语义判断或跨章扫描。相似度百分比不是正确性或重复概率，可能误报/漏报；只读展开全文不会保存检查位置、勾选合并项或改变题数。合并仍须用户逐题选择并填写原因。

个人导入入口支持只看带标记章节；章节内可筛选全部、待检查、异常类型、排除项和题目关键词。异常类型按有效题去重计数，展示页码与全部原因；上一/下一待检查题在当前筛选范围内循环，沿用 `PROGRESS` 保存位置。筛选不自动切换当前题，不改变章节确认范围；切换筛选会清除合并选择，避免隐藏选项误入合并。未保存编辑、待同步或待处理写入继续阻止切题和新的写入。异常必须逐项人工核对，在原编辑流程中移除标记、填写原因并确认保存，不批量清空。

原文面板按需加载既有 PDF.js 阅读器。大屏两列，右侧原文保持可见并独立滚动；窄屏按顺序排列，PDF 放大只在阅读器内部滚动。每个来源段落均可选择，跨页与同页多个范围分别保留，高亮当前有效 bbox；编辑中明确标注边界未保存，无效边界不高亮。个人资料沿用 `/api/sources`，平台资料沿用 `/api/admin/library/{id}/sources`，仍由服务端验证归属/管理员权限。加载失败提供重试和原 PDF 入口。

检查页展示章节/草稿版本、草稿及来源 ID、原始提取证据，以及既有历史中的时间和输入/输出 ID。预览复用同一次草稿读取，避免编辑区与预览独立取数。显示修订只经既有 `EDIT` 写入；原始 PDF 和提取证据不被覆盖，正式卡片 ID 与学习记录保持原有保护。个人操作继续进入 IndexedDB 幂等队列，平台操作继续使用受控在线写入；无新增本地学习状态或备份格式。

验证与边界见 [P1-02 验收记录](../fixtures/p1-02/README.md)。
