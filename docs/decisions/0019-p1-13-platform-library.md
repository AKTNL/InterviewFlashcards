# ADR 0019：平台命名空间、发布快照与独立领取

- 日期：2026-11-01
- 状态：采用；仓库实现与本地验收，尚未发布公网
- 对应：P1-13，依赖 P1-09、P1-12

为每个公共知识库创建独立、不可登录的平台内容命名空间，显式记录 `space_kind=PLATFORM` 与 `platform_library.owner_id`。数据库约束密码、状态和角色，用户管理接口排除该身份；不会把管理员私人空间变为公共内容，也不计入账号准入额度。复用现有内容归属外键、PDF 解析 worker 与逐章检查事务，避免另建一套易偏离的内容模型。

首期每库一份 PDF，全部非放弃章节确认后发布。已发布内容冻结成不含个人状态的 P1-09 内容快照；目录只开放清单和已确认文字预览，来源 PDF/图片由领取后的个人鉴权 API 读取。私人分享接口及接收账号绑定规则保持独立。管理员先下架再修改，再次发布递增内容版本，不能影响旧副本。

将 P1-09 的独立副本复制步骤提取为共享服务，保留其文件哈希、配额、ID 重映射和事务清理。每账号每库永久一次领取，标记不进入个人 ZIP；恢复或删除个人副本不会成为再次领取或恢复平台状态的途径。

领取锁接收账号后锁平台库；管理锁平台命名空间后锁平台库。知识库行串行化领取、下架、删除与发布，源内容在发布期间禁止修改。删除立即停止授权并撤销 worker 令牌；清理至少延迟 7 天，检查有效任务与其他引用，只清理已删除平台命名空间的资源。文件清理在引用检查事务提交后执行，数据库记录回收结果；崩溃可再次检查重试。已有个人副本没有共享资源 key。

平台创建/管理与审计不随个人恢复回滚，整站数据库/文件/临时卷快照包含平台全量状态。具体接口及状态见 [API](../api/platform-library.md)，验证见 [验收记录](../fixtures/p1-13/README.md)。
