# ADR 0013：HTTPS 发布与本地集成验收

- 日期：2026-10-31
- 范围：P0-13；按用户本轮要求先完成本地验收，服务器部署随后执行。

## 决策

生产 Compose 独立于本地 HTTP 配置，直接由 Nginx 终止 TLS，后端与 PostgreSQL 不发布主机端口。证书由宿主机管理，完整证书目录只读挂载；代理模板只替换域名/HTTPS 端口，保留 Nginx 变量。生产强制 Secure Cookie，原生解析可信内部代理的协议头；代理覆盖外部转发头。HTTP 308 跳转、TLS 1.2/1.3、HSTS、静态 MIME 和鉴权均有实际检查。

采用不可变发布镜像引用、三个独立持久化卷、依赖数据库的健康检查和有限日志。新增启动时清理已中断的上传/发布暂存，保留已提交 UUID 文件，不进行业务资源垃圾回收。仍采用单 JVM，会话重启后失效。

发布自动化复用 P0-06/08/09/12 的业务操作和断言，适配本地 HTTPS 地址、隔离账号、当前重试按钮与题库详情入口；不修改历史验收记录。分为完整流程、容器重建后持久化、删除/重置与异常恢复三个阶段。默认只允许固定的 localhost 隔离环境，不能传入真实用户账号或公网目标。证书信任检查通过独立 Python 工具完成；手机浏览器仿真不替代实体手机验收。

首次加载时，学习偏好或计划可先于同步快照返回。设置、每日计划和单题练习的写入按钮与提交入口均等待同步基线就绪；连接完成保留已输入内容和已展开答案，避免在不可提交时显示可操作入口。

重新进入同一题的练习入口时，IndexedDB 历史成功收据不能触发自动导航；只有本次发起或刷新前尚未确认的原始开始操作可引导进入会话。评分收据恢复仍读取服务端最新会话，避免重复练习误进入旧批次。

## 运维边界

升级迁移由 Flyway 正向执行，不承诺自动降级。升级前停写，保存一致数据库/文件快照、旧镜像和旧配置。整库回退在新项目/新卷恢复后验证，切换数据代次隔离旧设备操作；应用内 ZIP 恢复仍走既有预检/明确确认/原子替换机制。

本地证书仅用于回环演练，不能作为公网证书使用。用户域名的系统信任链、续期、实际手机/电脑接续及公网发布仍需后续真实环境签收；未完成这些项目不宣告 M5 或第一版已发布。
