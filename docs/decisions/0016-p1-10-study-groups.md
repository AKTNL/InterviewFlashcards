# ADR 0016：小组关系独立于个人恢复，摘要按当前授权读取

日期：2026-11-01。状态：接受。

P1-10 允许朋友互相督促，但注册、领取题库不表示加入小组，也不表示同意共享个人学习数据。

## 决策

- 新增 V13 三张社会关系表，绑定已有账号。只有组主向指定账号发限时邀请，接收方说明范围后主动加入；加入只授权昵称可见，摘要默认关闭，再逐组单独授权。
- 小组、邀请、成员和授权不进入个人备份白名单，不复用会被个人恢复删除的学习写入收据；摘要也不存入收据。创建及邀请以稳定客户端 UUID 防止网络重试产生副本，接受邀请对已有资格幂等，授权使用持续递增的成员版本。
- 摘要直接复用个人有效事件统计，增加近 7 个学习日天数；仅返回日期、时区、是否学习、新学/复习数、学习天数。不同设备不使用本机自然日。现有产品统一 `Asia/Shanghai`，不在此任务独立开放用户时区。
- 组行作为授权事务边界：读取摘要取共享锁，成员/邀请/授权写入取排他锁；成员变更不依赖他人个人 revision。撤回/退出后新的查询立即禁止。退出撤销旧邀请，再加入时授权关闭且成员版本递增，旧授权请求不能重新开启分享。
- 组主离开解散小组，避免孤立组；首期不提供角色转让、公开搜索、排行榜或催学消息。按小范围试用执行 5 个创建组 / 每组 50 位成员 / 50 个有效待接受邀请上限。
- 前端在线操作，不缓存摘要、不加入离线重试队列；每 15 秒、前台激活和联网时重新查询，失败或隐藏时清除旧摘要。服务端提交后禁止新读取，已经传输的信息无法收回。

## 影响

个人备份恢复仅替换学习空间，当前社会关系与授权保留当前状态。已退出的成员及已撤回的授权不会从旧包恢复。题库复制与小组加入始终是两个独立操作。

组详情最多对 50 位已授权成员读取有效统计，优先保证统计与本人一致；未来确有负载时再优化查询。详情在读取期间阻塞同组授权变更，避免权限检查与返回数据之间出现竞态。API 与验收见 [小组 API](../api/study-groups.md)、[P1-10 记录](../fixtures/p1-10/README.md)。
