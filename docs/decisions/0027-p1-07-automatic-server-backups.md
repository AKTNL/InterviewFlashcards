# ADR 0027：复用一致快照的服务端自动备份

日期：2026-11-01。状态：采纳，仓库实现；线上启用另行执行。

P1-07 要求自动备份、明确的保留数量和空间、可见失败状态及实际恢复验证。个人 ZIP 只包含个人学习资料，无法恢复账号、平台内容及管理审计；采用已有 P0-13 的停写整站快照，以保持数据库与不可变文件一致。当前单机规模接受凌晨短暂停机和会话失效，不引入数据库持续归档或新守护服务。

以 Python 标准库实现独立调度命令，systemd 日/周 timer 执行。配置明确计数、字节上限、剩余空间预留与成功记录最大年龄；原子状态文件和非零退出保留失败证据。调度锁与手动工具共享维护锁避免相互干扰。运行镜像按容器 image ID 保存，隔离恢复固定使用同一版本；快照所有文件重新计算校验和，成功标记在正式服务恢复后写入。

新副本完成后才应用保留策略，最新副本与最后实际恢复成功的副本始终受保护；首次自动备份必须真正恢复到独立卷。无法同时满足保护与容量时失败，不删除恢复点。陌生、损坏及未完成目录只报告、计入空间，人工排查后处理。周检比较全表数据指纹、完整文件集合和内容、真实 TLS/数据库健康，失败保留现场；不自动切换生产。

这不是异地容灾：快照需外存，镜像与证书/凭据独立保存，Docker 数据分区需预留解压/恢复空间。快照后的客户端未同步修改不在服务端范围；正式回退继续执行停写及代次切换。没有数据库迁移、产品 UI 或个人 ZIP 格式变更。
