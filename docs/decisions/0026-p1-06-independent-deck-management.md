# ADR 0026：按稳定题库 ID 管理范围与重复提示

- 日期：2026-11-01
- 状态：采用，仓库实现与本地验收完成，尚未发布公网
- 依据：开发文档 P1-06，现有 deck、来源指纹、复习状态及学习范围模型已支持多题库。

## 决策

1. 新增题库管理总览，按题库 ID 分别聚合已确认章节、学习范围、正式题数、已学、到期与薄弱；包括空题库。名称仅用于显示，所有链接、范围设置、删除和重置使用 ID，同名题库显示完整 ID。
2. 浏览题库立即切换并清除旧模块/章节和分页，保留关键词与状态筛选；卡片结果展示题库归属。浏览范围与每日学习范围分开，不因浏览触发保存或重置进度。
3. 学习设置按题库 ID 查看并批量选择/暂停显示的章节，保留隐藏题库选择；继续整体提交原学习偏好版本。每日目标保持全局共用，暂不引入每库独立每日配额。
4. PDF 重复用 SHA-256 提示；直接上传继续用户内去重，授权领取继续独立副本。正式题按标题移除空白和转小写提示重复，支持在题库筛选内分页核对。不会根据标题自动合并答案或复习记录。
5. 清理完整副本复用 P0-12 的影响预览、显式确认、幂等收据、修订和会话失效，新增入口只预选目标；单卡删除、跨库合并和语义查重留后续需求。删除后重新查询提示，保留原资料不算仍存在的重复题库。
6. 总览查询使用同一个一致性事务，来源、重复提示及卡片查询均限定当前用户。页面跟随现有修订/跨日刷新，失败撤下旧统计并允许重试，避免将缓存进度误报为当前结果。现有 ZIP、同步模型与数据库结构无需变更。

## 代价与边界

重复标题可能具有不同答案，提示不能代替人工核对；不同标题的同义问题不会识别。总览返回全部摘要与来源，标题查重依赖查询计算，适用于现有规模；超大题库需基于实际负载再设计索引和分页。题库进度包含暂停章节，首页每日任务仍只使用所选章节，界面和 API 均说明该差异。
