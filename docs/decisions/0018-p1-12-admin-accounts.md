# ADR 0018：管理员与普通用户业务权限

日期：2026-11-01。状态：采用。对应 P1-12。

采用 USER / ADMIN 两种角色和稳定能力集合；不根据用户名推断权限。V15 所有旧账号默认 USER 且启用，保留预置身份绑定与原密码。独立管理员通过离线交互命令创建，或维护者精确绑定旧账号；应用启动不自动提升账号。角色授予回收只走受控维护入口，Web 管理普通用户。

逐请求检查数据库角色、状态和凭据版本；初始/重置密码只能先改密。管理员仍以本人身份访问学习空间，管理接口仅返回账号与容量元数据，不扩展私人内容访问范围。P1-13 平台知识库和 P1-14 Dashboard 留独立任务，后台只提供标明未实现的入口。

复用 registration_guard 串行化账号准入、角色调整和后台写入。管理建号单独永久分配记录，与既有注册成功数相加，避免破坏邀请人历史记账；受环境开关与全站上限约束。首个管理员的离线初始化允许注册关闭，但不绕过上限。Web 不能修改管理员，维护降级在锁内检查至少保留一个启用 ADMIN。

管理操作独立于个人同步 revision 和离线队列。管理版本检测过期请求；建号另用 operationId 收据防止响应丢失后重复建号。请求指纹加盐 BCrypt 保存，不记录凭据。密码只交付线下，前端提交/卸载时清除，初始及重置密码要求首次修改。

成功审计与业务同事务，服务层失败另记结果；维护操作标记 MAINTENANCE，Web 记录实际操作者。个人 ZIP 保持学习数据白名单，不能还原权限、停用状态、邀请码、计数或审计。全站配置后台只读，修改仍使用部署环境与受控重建。

小规模管理查询按页实际计算文件用量，最大 50 人/页；未来大量用户时再增加服务端容量汇总缓存。Web 写操作在全站行锁内执行 BCrypt，会短暂阻塞其他注册/管理请求，正常学习不使用此锁。
