# ADR 0023：个人按周记录、章节变化与遗忘排序

日期：2026-11-01。状态：采用，仓库实现与本地验收完成，尚未发布公网。

P1-03 增加个人 `/trends` 页面及只读 `/api/learning-trends` 接口，从导航和今日学习进入。首期按最近 4/8/12/52 周查看，服务端允许 1～52 周；每周从上海自然日周一开始，本周截至今日。统计只依赖既有有效学习事件和当前调度状态，无迁移、统计缓存或新备份字段。

首页摘要与趋势抽取相同的有效事件 CTE：RATE/CORRECT，排除被撤销或替代的原事件。必须先从全部历史确定首次学习日，再筛选所需区间。新学按不同卡片计，复习按卡片和学习日计；同日重练仅增加明确标注的自评次数。每周分别展示学习量柱形、自评结果和学习天数，避免把练习次数当成新增已学或掌握率。无学习的周补零。

章节变化比较区间开始前和当前的最后有效评分，展示已学/薄弱题数及差值、区间新学/复习、自评次数和当前最近自评分布。当前正式章节全部纳入，暂停不丢历史。题库名称、章节名称和卡片数取当前值，删除、重置和个人恢复会改变剩余历史，因此页面明示这不是历史内容快照。薄弱变化不能解释为客观能力变化。

遗忘排序复用复习状态中的 lapse_count，首评或跨日不会计一次，同日重练不增加。历史遗忘但当前已记住的题仍可查看，按次数降序、到期日、卡片 ID 稳定分页，点击进入原卡片阅读/练习；周数范围不截断累计遗忘数。与现有评分、撤销、更正和 ZIP 恢复共用状态，不另行累加 FORGOT 行数。

查询以会话绑定用户，在 REPEATABLE_READ 只读事务内聚合，保留既有用户复合归属连接；同次响应时间和日期由一次 Clock 读取确定。页面按修订/学习日/代次及激活刷新，旧响应隔离，失败移除旧数据；无需将派生统计写回同步队列。接口详情见 [学习趋势 API](../api/learning-trends.md)，验证见 [P1-03 验收记录](../fixtures/p1-03/README.md)。
