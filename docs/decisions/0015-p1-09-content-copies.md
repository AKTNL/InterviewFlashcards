# ADR 0015：授权领取一次性题库内容副本

- 日期：2026-11-01
- 状态：采用，已通过本地验收；尚未发布公网
- 对应：P1-09，依赖 ADR 0014

## 决策

选择一个题库，分享其中已确认章节的正式内容。来源 PDF 整份提供，创建和领取两端都显示全部物理页范围；不允许把“只分享已确认卡片”误解为“只提供这些 PDF 页面”。首期不提供按页裁切或任意章节选择。

使用服务端生成的内容专用 JSON 快照与快照文件，不复用个人备份。保留题目、完整原文/展示内容、纠错、适用版本、追问、标签、来源、图片和待检查标记；排除个人整理、调度、偏好、会话、收据、账号和未确认草稿。仅生成必要的支持编辑的草稿关联，不复制解析原始证据和其他章节内容。

邀请绑定一个既有账号，最多领取一次，有效期 1～168 小时，可撤销。邀请 ID 为随机 UUID，但它不是匿名访问凭据；所有接口执行账号归属校验。接收者登录后在邀请收件箱主动确认，不自动建立小组关系。

领取采用现有幂等事务和新 ID，全部卡片从未学开始，学习范围由本人选择。文件经长度/指纹检查后复制到新存储 key；源、快照、接收副本不共享可变文件记录。为兼容接收者已有相同 PDF，V12 增加 `source_document.shared_copy`：普通上传仍通过部分唯一索引去重，内容副本不参与上传去重。每份来源拥有独立导入关联，保留后续编辑、PDF 阅读和备份能力。

`deck.copy_origin` 保留来源清单、源修订、快照 ID、内容哈希和各卡片源内容版本；备份恢复时这些证据不做 ID 重映射。格式 1 旧备份缺少新增字段时补默认值。个人恢复不会恢复授权；发出的邀请在恢复事务中撤销并清理快照文件。

## 并发与失败

领取与撤销按邀请行串行化，先完成的一方决定结果；已经领取的副本不会被撤销收回。数据库提交失败时通过事务回调删除本次发布的文件，收据与题库在同一事务内提交；快照文件仅在领取/撤销事务提交后删除。

账号写屏障统一使用 PostgreSQL `FOR NO KEY UPDATE`。它仍排斥同账号业务写入、恢复和 `FOR SHARE` 快照，但允许跨账号邀请的外键 `KEY SHARE` 检查；账号主键从不改变。原先 `FOR UPDATE` 会使双方互发邀请或领取/撤销中的外键检查死锁。恢复在容量锁之前锁定并撤销邀请，保持与领取相同的顺序。竞争、互发和恢复撤销场景均有真实 PostgreSQL 回归。

## 首期边界

每个所有者最多保留 20 份未领取且未撤销快照，单份结构化内容最多 16 MiB；文件计入个人/全站配额。领取先检查累计文件大小和新增来源数。过期邀请不会继续授权，所有者可撤销以释放空间；历史清单最多显示最近 100 条。不增加公开分享、匿名文件下载、离线自动领取、实时共同编辑或批量广播邀请。
