# ADR 0008：三档调度与可撤销学习事务

- 状态：采用
- 日期：2026-10-31
- 依据：开发文档 §4.9、§5；ADR 0001

P0-08 使用纯函数 `ReviewRules`，输入旧状态、评分、服务端时间、学习时区、间隔表和新版本，输出状态与是否同日重练。默认算法 `rules-v1`，间隔 1/3/7/14/30 天，阶段 -1～4；参数变化必须更换算法版本，事件记录实际采用版本，不重算旧安排。

复用用户锁和 MutationService 事务，评分同时保存前后状态、当前队列快照、学习日、事件顺序及会话提交版本。卡片增加独立单调复习版本，保留在未学状态下，避免撤销首次评分后旧请求利用版本回到 0 重放。正文、笔记和复习使用各自版本，编辑内容不清空调度。

同日所有额外练习均不升级阶段、不增加遗忘次数；最新评分仍可改变薄弱状态。不记得/模糊最多提前到次日，不能延后既定日期。数据库额度表以用户/卡片/学习日唯一，同时约束用户/会话/卡片唯一。额度指向产生它的事件；撤销原事件时只归还该事件额度，恢复原队列；跳过保留额度，重建会话不能无限追加。

撤销记录补偿关系，不删除审计历史；仅当前用户最近有效事件、同一会话、无后续会话及复习变更时允许。恢复前状态及队列时版本递增。有效事件查询排除补偿行及已被补偿的原事件，统计从有效历史核对。重新学习是显式确认的独立事件，保留首次学习和历史，不再次计为新题。

学习入口明确选择单题或本页，服务端保存有序队列；客户端默认隐藏全文和评分，已确认收据后才前进。会话跨天变为只读，重新进入时按当前状态创建新条目。每日目标/范围/自动到期队列属于 P0-09，不在 P0-08 提前定义；评分候选识别、显式冲突更正和全范围刷新属于 P0-10。本阶段并发旧状态评分返回双方可核对内容，拒绝重复推进，不静默覆盖。
