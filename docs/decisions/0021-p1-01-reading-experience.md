# ADR 0021：本机阅读偏好与标签页阅读位置

日期：2026-11-01。状态：采用，仓库实现，尚未发布公网。

P1-01 为卡片详情和主动回忆页增加字号、阅读主题及桌面快捷键。共享 `ReadingPane` 管理阅读界面；默认 18px、明亮，可选 16/18/20/22/24px 和明亮/暖纸/深色。主题限于阅读面板，导航和编辑表单保持各自的可读配色，PDF 保持来源原貌。

阅读偏好是设备上的展示选择，以版本化 localStorage 键按账号保存；阅读状态以 sessionStorage 按账号、dataEpoch、卡片展示修订区分。练习额外绑定会话、当前条目和预期复习版本，因此同一题的新练习或下一条目不会沿用已展开答案。保留最多 80 条位置，只记录展开开关、段落锚点、滚动偏移及 details 索引，不保存题目、答案或笔记。离开、刷新和滚动停止时保存，返回时在数据与 DOM 就绪后恢复；原图预留纵横比，降低延迟加载造成的位置移动。关闭标签页、浏览器回收数据或变更展示修订后不承诺恢复旧位置，提供“从头阅读”。

不将阅读状态写入业务同步队列、revision、ReviewEvent 或个人 ZIP，不增加服务端表和迁移。存储不可用时允许继续调整和阅读，并提示保存失败；读取损坏记录时回退默认。恢复学习空间后旧代次位置不会重放。

空格切换完整答案，H 切换提示，练习中 1/2/3 分别评分。可关闭全部单键快捷键。输入控件、可编辑区域、链接、按钮、summary、阅读设置、打开的模态框、选中文字、输入法组合、修饰键、后台页面和长按重复事件不触发。数字键只在答案展开且允许评分时调用原有 `write('RATE')`；待同步、加载、会话失效、版本不匹配和提前练习确认继续受原有事务与交互约束保护。

卡片和原图来源链接携带卡片 ID；练习来源还携带会话 ID。来源阅读页只接受本地固定路由所需的 ID，提供返回原练习入口；服务端仍重新读取会话，其他设备已推进时显示当前条目，不回放旧队列。
