# 0012 · 手机阅读、异常状态与题库数据操作

日期：2026-10-31。

1. 数据操作从学习设置进入，按单个题库预览并确认。删除内容和重置历史使用独立文案；操作前提供完整备份入口。避免为清除一套资料误清空整个学习空间。
2. 删除保留原 PDF、图片资源和提取证据，资料任务显示“题库已删除”，需要明确重试才能重新导入。文件物理清理留后续资源回收任务；保留来源的行为在确认前说明。
3. 重置彻底移除目标题库学习历史及复习日期，回到未学；需要保留历史的巩固操作使用单题重新学习。两者的新增计数含义在确认前分别说明。
4. 复用用户写锁、修订号、幂等收据和 IndexedDB 队列。预览后发生任何业务写入都要求重新确认，失败不能伪装为成功；不更换数据代次，使其他题库的离线编辑仍能按既有实体版本处理。
5. 含目标题库的混合批次整体失效，保留其他卡片历史，移除目标条目以释放外键。提升目标卡片复习版本、删除待处理评分候选；在会话写入的候选识别之前拒绝失效会话。失效读取不暴露当前条目、不可撤销，不进入续学列表。
6. 360px 阅读列内允许正文和长标识换行，表格独立滚动；三档评分保持文字、焦点和至少 44px 触控面积。图片可打开鉴权原图或来源 PDF。顶部导航换行，所有操作区域限制在可用宽度内。
7. 未保存内容在表单和离开/关闭时提示，已入本地队列和服务端确认分别显示。退出先通过页面离开保护，再调用退出 API；退出失败显示错误，待同步状态需明确核对。
