# ADR 0007：正式题库、个人整理和 PDF 原文核对

- 日期：2026-10-31
- 状态：采用
- 范围：P0-07

正式查询由独立题库服务提供，按用户空间和现有 deck/module/chapter 关系筛选；稳定分页仅包含正式卡片，保留章节导入状态与数量供用户识别未确认范围。关键词为字面题目子串，保留 PostgreSQL 参数化查询。复习筛选读取当前状态，不在本阶段生成评分。

个人整理使用既有 personal_annotation，笔记、提示、要点与收藏作为一个独立版本对象。技术纠错和适用版本通过 V6 添加到 card，标签复用现有 tag/card_tag；元数据使用 card.version。正文、来源和待检查标记继续进入 P0-06 的章节聚合与审计流程，避免草稿、正式内容和来源关联分叉。未知适用版本保留 null。

全部修改复用 MutationService 的用户事务锁、幂等收据、代次和修订号。前端接入同一 IndexedDB 队列；冲突保留双方，明确重提使用最新对象版本。内容编辑不会删除或重新创建 review_state/review_event，也不替换正式卡片 ID。

阅读保留原文提取与人工展示修订，技术观点单独展示为个人技术纠错。默认收起完整答案和提示，追问各自展开；待检查的摘要提醒始终可见，详情原因按需展开。提取阶段无法可靠还原的代码、表格仍保留文本和明确来源，原始证据和原 PDF 可直接核对；不自动猜测结构或摘要化。含图片内容自动呈现整页原图，明确说明包含周边内容。

采用固定版本 PDF.js 5.4.624，在网站内绘制来源页，手机无需依赖系统 PDF 插件。物理页码沿用 PDFBox 的从 1 开始页码和左上角坐标，高亮对应来源范围；本地打包 worker、cMap、标准字体和 wasm。保留浏览器打开原文件兜底。当前 PDF 验证范围内无旋转页；更多排版、PDF 全文搜索/文本选择和实体手机验收不作为本阶段已验证能力。
