# ADR 0024：个人复习参数与效果观察

- 日期：2026-11-01
- 状态：采用，仓库实现与本地验收完成，尚未发布公网
- 依据：开发文档 P1-04；M5 已签收，线上已有学习记录。本次在隔离数据库使用构造事件验证语义，不修改或读取线上私人评分内容。

## 决策

1. 允许每个账号配置五阶段成功间隔，每档 1～365 天且非递减。保留三档状态转移、次日重试和同日重练保护。每日新题量和批量继续独立设置。
2. 个人配置采用追加历史，不可覆盖旧版本；生成独立算法 ID，必填变更原因。未设置时使用现有部署默认参数。用户锁序列化参数和评分写入，新版本只用于后续 RATE/RELEARN，不扫描重算复习状态。
3. 新事件保留版本与完整参数快照。UNDO 复制原证据；CORRECT 必须使用被更正评分的参数，避免一次纠错同时变更算法。对于无证据的历史自定义版本不猜测，只允许接受当前结果后新练习。
4. 效果观察按照“安排 → 下一次跨日到期自评”归因到安排版本。保留 dueDate 的重练不抢占旧安排归因，缩短到期日的重练产生新安排。首次、同日重练、提前评分和显式重新学习不冒充效果样本，撤销和更正复用有效历史口径。
5. 展示样本数、不同卡片数、三档自评、准时/逾期以及平均安排/逾期天数，和包含首次/重练的评分活动分开。只支持 30/90/180 天个人观察，不给算法排名、自动调参或因果结论；尚无真实后续样本时显示空态。
6. 配置使用标准 mutation 协议在线保存，响应不明时保留同一请求用于核对，不另建离线协议。版本冲突要求重新读取核对，输入不被修订刷新覆盖。
7. 参数属于完整个人学习空间，纳入同步与 ZIP；旧格式 1 可恢复，旧事件参数缺失明确保留未知。单题库删除/重置保留账号参数，题库分享不传播参数，跨账号恢复重绑定归属。

## 后果

V18 与前后端一起升级；修改参数不改变已存在日程，效果需等下一次真实到期复习才能观察。旧版本可能有未知参数分组，不能从当前间隔反推过去配置。配置历史全部保存但页面只展示最近 20 条。部署默认参数仍按旧运维方式管理，修改间隔必须更换部署算法版本名；个人用户推荐从界面创建带原因的版本。
