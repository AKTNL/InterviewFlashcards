# ADR 0009：每日学习范围、额度与可恢复队列

- 状态：采用
- 日期：2026-10-31
- 依据：开发文档 §4.10、§3.3；设计文档 §6；ADR 0008

首次使用返回新题 5、复习 20、无参考时长的建议，范围为空，用户明确保存后才生成自动计划。设置使用独立乐观锁及原写入队列，章节仅允许当前用户已确认内容；范围为空表示全部暂停。限制新题 0～100、批量 1～100、参考时长 1～1440 分钟，以限制单轮体量，并允许多轮处理全部到期题。

配额按服务端学习日的有效历史计算，包含自主练习的新学数；不以已经取出的新题或本地计数预扣额度。复习批量只截取新轮，首页始终展示全范围到期总数。混合轮先到期后新题；到期按逾期程度、最近较差评分、稳定 ID；新题按目录顺序和稳定 ID。

每日计划与题库自主练习共享既有评分、撤销、有限重练和收据事务。V8 只增加会话模式、创建时间与条目类型，不改旧迁移。每日计划同模式同日优先继续原有有效队列，避免反复点击建立重复轮。

保存服务端原始队列，读取时对范围、版本、到期集合及新题余额生成有效视图，评分写入在用户锁下重做同样核对。暂不删除不再符合条件的条目，保留 unavailable 及原因；恢复范围或提高目标后，原未完成条目可以再次符合条件。设置写入推进当日自动会话版本，避免旧界面误评分。手动题库练习允许显式练习范围外或未到期卡片，保留 P0-08 的提前确认规则。

首页展示当日有有效剩余项的会话；跨天旧会话不出现在继续列表，只能读取历史。重新进入自动计划以今日的额度和到期集合创建新轮。日期由服务端上海时区决定；暂停、恢复、修改目标和跨天都不批量重算历史或 dueDate。

本轮回顾从有效评分统计新学和此前已学的复习卡片数，单独查询最新仍薄弱的卡片。撤销和同日重练复用原规则，不引入学习量累加计数器。结束只表示本批处理完，首页仍可开始后续批次。

前端只对本次用户创建计划的已确认收据跳转；初始化载入历史收据只更新摘要。设置刷新后恢复的待同步操作在确认时重新读取实际设置，避免继续编辑旧版本。完整业务同步、评分候选更正和通用冲突解决仍由 P0-10 实现。
